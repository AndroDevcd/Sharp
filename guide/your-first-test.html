Your first test

Tests are an ordinary program that uses std.testing:

mod app;

import (
    std.testing
)

def add(a: decimal, b: decimal) : decimal { return a + b; }

def main() {
    tests("adding") {
        test("two and two is four") {
            expect(add(2, 2)).should_be(4);
        };
        test("adding zero changes nothing") {
            expect(add(7, 0)).should_be(7);
        };
    };

    finish_tests();
}
adding
  ok    two and two is four
  ok    adding zero changes nothing

all 2 tests passed

The program's exit code is 0 only when every test passed. Mocks (mock<an_interface>()) and stand-ins for injected objects are shown in the README and in examples/testing.
