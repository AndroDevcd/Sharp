Install

Download sharp-<version>.zip from the latest release and unpack the WHOLE archive (the installers need the folders next to them). START-HERE.txt inside says the same as below.

Windows - open the windows folder and double-click win-install.cmd (or run it in a terminal).

Linux (64-bit x86) - in a terminal, inside the unpacked folder:

bash linux/unix-install.sh

Raspberry Pi, or any other Linux - the VM is built on the machine itself:

git clone https://github.com/AndroDevcd/Sharp.git
cd Sharp
bash build-scripts/linux/install_from_source.sh

The installer needs no administrator rights. It copies Sharp into your user folder (Windows: %LOCALAPPDATA%\Sharp, Linux: ~/.sharp), adds it to your PATH, and then compiles and runs a small program to show that everything works.

Open a NEW terminal afterwards - a terminal that was already open does not see the new PATH. (A terminal inside an IDE sees it once the IDE itself is restarted.)

To remove Sharp again: win-uninstall.cmd on Windows, sh unix-uninstall.sh on Linux.
