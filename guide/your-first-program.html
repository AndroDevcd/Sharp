Your first program

Put this in a file called hello.sharp:

mod app;

def main() {
    name := "world";
    println("hello, $name!");
}

Compile it, then run it:

sharpc hello.sharp -o hello
sharp hello
hello, world!

There are two commands:

sharpc file.sharp -o namethe compiler: writes the program name. The standard library is always included. Add -O to make the program faster; sharpc --h lists every option.
sharp nameruns a compiled program

Every file starts with mod <name>; (the module it belongs to), and a program starts at main.
