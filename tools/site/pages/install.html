Get Sharp {version}

Download the zip, unpack the whole archive, then run the installer for your system. Open a new terminal afterwards so that sharp and sharpc are on your PATH.

Download Sharp {version} One zip for Windows and 64-bit Linux. All releases

Windows

Double-click the installer inside the unpacked folder.

windows\win-install.cmd

Linux, 64-bit x86

Run the installer from the unpacked folder.

bash linux/unix-install.sh

Raspberry Pi and other Linux

Build the VM on the machine itself.

git clone https://github.com/AndroDevcd/Sharp.git
cd Sharp
bash build-scripts/linux/install_from_source.sh
