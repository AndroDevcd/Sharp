The Sharp programming language

Dependency injection, mocks, tests and GUI apps, all built in.

Sharp ships with the tools most projects have to piece together from third-party libraries. Programs compile with sharpc and run on the Sharp VM.

mod app;

interface greeting {
    def words() : string;
}

class friendly : greeting {
    override def words() : string { return "Good morning"; }
}

class door {
    inject hello : greeting;            // the door asks for a greeting; it never makes one

    def open(name: string) { println("${hello.words()}, $name!"); }
}

component app {
    single { friendly() as greeting }   // this one line decides which greeting everyone gets
}

def main() {
    door().open("ada");
}
mod app;

import ( std.c )

extern "c" {                                // C's own library, under its C names
    def strlen(text: string) : c_size;
    def abs(number: c_int) : c_int;
}

def main() {
    println("strlen says " + strlen("hello, C"));
    println("abs says " + abs(0 - 42));
}
mod app;

import ( std.testing )

interface weather {
    def today() : string;
}

def advice(sky: weather) : string {
    if(sky.today() == "rain") { return "take an umbrella"; }
    return "enjoy the sun";
}

def main() {
    tests("what to take") {
        test("a rainy day needs an umbrella") {
            sky := mock<weather>();                     // no fake class to write
            given { sky.today(); }.returns("rain");     // pretend it is raining

            expect(advice(sky)).should_be("take an umbrella");
        };
    };
    finish_tests();
}
mod app;

def main() {
    name := "world";
    println("hello, $name!");
}

Why Sharp

Everything you'd normally install is already here.

Dependency injection

Write inject, bind it in a component, and you're done. No framework, no container.

Mocks without boilerplate

mock<mailer>() is all it takes. The compiler writes the class.

Testing out of the box

std.testing comes with the language, so there's nothing to install or configure.

GUI apps in about 30 lines

std.guikit is ready when you are. Change the state and the screen follows.

Concurrency that scales

Coroutines and channels run thousands of tasks on just a few threads.

Modern by default

Null safety, generics, closures and type inference from line one.

2.2×

Performance

About as fast as LuaJIT.

On six Benchmarks Game programs, Sharp with -O takes 2.2 times as long as the fastest language. That is ahead of PyPy and Mono, and up to 160 times faster than Sharp was in 2020.

Get started

Up and running in three steps.

1

Install

Unzip the release and run the installer. You don't need admin rights.

2

Compile

sharpc compiles your code.

3

Run

sharp runs it. It works the same on Windows and Linux.

# compile, then run
$ sharpc hello.sharp -o hello
$ sharp hello
hello, world!
