sdb, the Sharp debugger

See what your program is doing.

sdb runs a Sharp program and lets you stop it, look at it and change it. It comes with Sharp and works in any terminal.

Start it

Build with -dbg, then run the program under sdb.

$ sharpc notebook.sharp -dbg -o notebook
$ sdb notebook

What you get

  • Your source, variables and call stack on screen while you step
  • Breakpoints by function, by file and line, or by line alone
  • Change a variable while the program is paused
  • Every thread and fiber, and what each is doing
  • Tab completion and breakpoints saved in sdb.json

The commands you'll use most

break notebook.sharp:41Stop when the line is reached
continueRun to the next breakpoint, or the end
nextRun to the next line
intoGo into the function the line calls
outRun until the function has returned
print <name>What a variable, a field or an element holds
set <name> = <value>Give it a new value
backtraceThe calls that led here
threadsEvery thread and the fiber it runs
