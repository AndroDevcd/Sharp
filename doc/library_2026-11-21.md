# The library, 21 November 2026: the network, data and security

What was added to the standard library in this round, with one example each. Every file
starts with a comment that says more; the suite case named beside each part shows it in use.

Everything here is Sharp: the operating system's own libraries are called directly through
`extern` blocks. Nothing has to be installed beside Sharp on Windows or Linux.

## A server you talk to: `http_service`

One class per server; each function of it is one line. The verb is the function called, the
type in `<...>` is what the json answer becomes, the block says what goes into the request.

```
import ( std.net, std.data )

class user { login : string = ""; name : string = ""; public_repos : _int64 = 0; }
class repo { name : string = ""; stargazers_count : _int64 = 0; }

class github base http_service {
    github() {
        base_url("https://api.github.com");
        header("Accept", "application/vnd.github+json");
        retry(2, 200);
    }

    def user(name: string) : user {
        return GET<user>("/users/{name}") { path("name", name); };
    }

    def repos(name: string, page: _int64) : list<repo> {
        return GET<list<repo> >("/users/{name}/repos") { path("name", name); query("page", page); };
    }
}

def main(args: string[]) {
    hub := new github();
    print(hub.user("octocat").name + "\n");
}
```

The verbs are written in capitals (`GET`, `POST`, `PUT`, `PATCH`, `DELETE`), as HTTP writes
them: `get` and `set` are words the language keeps for itself.

For one request, without a class: `http.GET("https://example.com/").text()`, and with a block
`http.POST(url) { it.json("hello", "world"); }`.

A test hands a service a `fake_http` and nothing leaves the program:

```
fake := new fake_http();
fake.answer("GET", "/users/ann", 200, "{\"login\":\"ann\",\"name\":\"Ann A\"}");
hub.use(fake);
```

## json and your own classes

```
class address { street : string = ""; city : string = ""; }
class user {
    name : string = "";
    age : _int64 = 0;
    home : address?;
    tags : list<string> = new list<string>();
    photo_url : string?;                    // filled by "photo_url" or "photoUrl"
}

someone := json.to<user>(text);
everyone := json.to<list<user> >(text);
text := json.of(someone);
```

Nothing is written per class. A wrong value says where it is: `user.home.city: expected a
string, found a number`. An enum is written as its name and read from its name or its number.
Not read yet: hash maps (declare such a part as `json_value`).

## A server of your own: `http_server`

```
server := new http_server();
server.GET("/users/{id}") {
    found := users.find(it.number("id"));
    if(found == null) { throw new http_error(404, "no such user"); }
    it.json(found!!);
};
server.POST("/users") { it.status(201).json(users.add(it.body<new_user>())); };
server.files("/static", "public");
server.socket("/live") { while(true) { said := it.receive_text(); if(said == null) { break; } it.send("you said: " + said!!); } };
server.serve(8080);
```

Plain HTTP/1.1; for https put a reverse proxy in front.

## Compression: `std.compress`

```
small := gzip.compress(bytes);              same := gzip.decompress(small);
archive := zip_archive.open(new file("release.zip"));   archive.extract_all("unpacked");
made := new zip_builder();  made.add("readme.txt", "text");  made.save(new file("out.zip"));
```

Written in Sharp. It reads everything the formats allow; what it writes is a little larger
than what zlib makes (fixed codes), and is read by every tool.

## What changed below the library

- **The compiler.** Generic functions of one name may differ in their number of parameters
  (`GET<t>(route)` beside `GET<t>(route, extras)`), and a generic function may stand beside a
  plain one with the same parameters (`GET<t>(route)` beside `GET(route)`): a call says which
  it means by writing type arguments or not.
- **The compiler.** `reflects<T>()` (std.reflect) is known by name: for T and the class of
  every field under it, all fields and the constructor without parameters stay in the
  executable, so that objects can be filled by name. `reflects_whole<T>()` keeps all of T.
- **The VM.** Reflection was written again (reflection_2026-11-21.md): the VM answers
  questions about the program in numbers and names, and builds nothing when a program starts.

## One thing to know about strings

`name = "text";` on a string variable changes the string object itself: every variable,
field or caller that shares that object sees the new text.

```
a : string = some_function();
b : string = a;
b = "two";                  // a is "two" as well
```

Giving a variable another variable, or the result of a call, makes it refer to that other
string instead. When a string that came from somewhere else has to be replaced by a text in
quotes, write `b = new string("two");`.
