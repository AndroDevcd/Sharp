    class base64

    source

    Base64: writes any bytes with 64 harmless characters (A-Z a-z 0-9 and two more), three bytes becoming four characters. Used wherever binary data has to travel as text: e-mail attachments, data in JSON or XML, tokens.

    base64.encode("hello")              "aGVsbG8="
base64.decode("aGVsbG8=")           "hello"
base64.encode_url("\xfb\xff")       "-_8"       (URL safe, no padding)

    Two alphabets (RFC 4648): - standard: the two extra characters are '+' and '/', and the text is padded with '=' to a multiple of four characters - URL safe: '-' and '_' instead, which need no escaping in URLs and file names; written without padding

    Strings stand for bytes here: every character of the input of encode() is one byte (0..255), and decode() gives a string whose characters are the decoded bytes (it may contain any byte, including 0). The _bytes variants take and give byte arrays instead.

    Decoding accepts both alphabets, with or without padding, and skips line breaks, spaces and tabs (encoded data is often wrapped into lines). Anything else throws parse_exception.

    Everything is static.

    Functions

    static def decode(text: string) : string

    The bytes that text encodes, as a string with one character per byte. Both alphabets are accepted, padding is optional, white space is skipped. "" gives "".

    Throws parse_exception when the text contains a character that is not Base64, has padding in the middle, has a length that no input produces (one character left over), or ends in bits that are not zero.

    static def decode_bytes(text: string) : _int8[]?

    The bytes that text encodes as an array; null when it encodes no bytes at all. Accepts and throws like decode().

    static def encode(data: string) : string

    the bytes of data (one per character) in standard Base64 with '=' padding; "" gives ""

    static def encode_bytes(bytes: _int8[]?) : string

    bytes in standard Base64 with '=' padding; null gives ""

    static def encode_lines(data: string, line_length: _int64) : string

    Standard Base64 broken into lines of line_length characters with "\r\n" between them (MIME uses 76, PEM files 64). No line break at the end. Throws illegal_argument_exception when line_length is below 4.

    static def encode_url(data: string) : string

    the bytes of data in URL safe Base64 ('-' and '_'), without padding

    static def encode_url_bytes(bytes: _int8[]?) : string

    bytes in URL safe Base64 ('-' and '_'), without padding; null gives ""

    static def is_valid(text: string) : bool

    true when decode(text) would succeed

    class csv_exception

    base exception · source

    Thrown by csv_reader for text that is not well formed CSV: a quoted field that is never closed, or text directly behind the closing quote of a field ("ab"c). Also thrown by csv_writer and csv_reader for settings that cannot work (a separator that is a quote or a line end).

    line is the line of the text where the problem is (counting from 1, and counting the line breaks inside quoted fields too), column the place in that line (from 1). Both are -1 when the error is not about a place in a text. The message already contains them.

    Fields

    linedecimalline of the problem, counting from 1, or -1
    columndecimalplace within the line, counting from 1, or -1

    an error that is not about a place in a text

    public csv_exception(message: string, line: decimal, column: decimal) -> base(message)

    an error at a known place; message should already mention the place

    class csv_reader

    source

    Reads CSV (comma separated values) text: rows of fields.

    rows := csv_reader.parse("name,age\nAda,36\n\"Smith, John\",41\n");
rows.at(2).at(0)                  // Smith, John   (rows: list<csv_row>)
    reader := new csv_reader(new file("people.csv").read_text());
reader.set_separator(';');
header := reader.read_header();
while(reader.has_next()) {
    row := reader.next_row();
    name := row.at(reader.column_index("name"));
}

    The format (RFC 4180, with the usual freedoms): - a row ends at a line end: "\n", "\r\n" or "\r"; the last row does not need one - fields are separated by the separator: ',' unless set_separator() says otherwise (';' and tab are common) - a field may be put in double quotes; then it can contain separators, line ends and - written twice - double quotes: "say ""hi""" is say "hi". Outside quotes nothing is special but separator and line end: a quote in the middle of an unquoted field is kept as it is, and spaces around fields are part of the fields (see set_trim()). - rows may have different numbers of fields - an empty line is skipped (see set_skip_empty_lines()); a line with only separators is a row of empty fields

    A row is a csv_row. Malformed text throws csv_exception with the line and column: a quoted field that is never closed, or text right behind a closing quote.

    The whole text is in memory; rows are taken from it one by one. Configure the reader before reading the first row. Not thread safe.

    The next row. When read_header() was called before, the row knows the column names (csv_row.field). Throws illegal_state_exception when there are no more rows (ask has_next() first) and csv_exception when the row is malformed.

    static def parse(text: string) : list<csv_row>

    all rows of text, with the default settings (comma, double quote). Throws csv_exception for malformed text.

    static def parse(text: string, separator: decimal) : list<csv_row>

    static def parse_file(source: file) : list<csv_row>

    All rows of the file source, with the default settings. Throws io_exception when the file does not exist or is a directory, csv_exception for malformed text.

    def read_all() : list<csv_row>

    All rows that have not been read yet. An empty list when there are none. Throws csv_exception when a row is malformed.

    def read_header() : list<string>

    Read the next row as the header: the names of the columns. They are remembered for column_index(). Returns the names. Throws illegal_state_exception when there is no row to read, csv_exception when it is malformed.

    def set_quote(ch: decimal) : csv_reader

    Use the character ch instead of the double quote to enclose fields (the single quote is sometimes used). Returns this reader. Throws csv_exception when ch is the separator or a line end.

    def set_separator(ch: decimal) : csv_reader

    Separate fields at the character ch instead of the comma. Returns this reader. Throws csv_exception when ch is the quote character or a line end.

    def set_skip_empty_lines(enabled: bool) : csv_reader

    skip lines without any character (true, the default) or report them as a row with one empty field (false). Returns this reader.

    def set_trim(enabled: bool) : csv_reader

    Remove spaces and tabs around unquoted fields (true) or keep fields exactly as written (false, the default). Quoted fields are never trimmed, but spaces between a quote and the separator are then allowed. Returns this reader.

    class csv_row

    source

    One row of CSV data: its fields in order, and - when the reader read a header - the names of the columns, so that a field can be asked for by name.

    row := reader.next_row();
row.at(0)                 // the first field
row.field("email")        // the field in the column called "email"
row.size()                // how many fields this row has

    Rows of one file may have different numbers of fields. A row can also be built by hand to give to a csv_writer:

    row := new csv_row();
row.add("Ada").add("36");

    class csv_writer

    source

    Writes CSV (comma separated values) text: rows of fields, quoted where needed so that a csv_reader with the same settings reads back exactly the same fields.

    out := new csv_writer();
out.write_field("name").write_field("age").end_row();
out.write_field("Smith, John").write_number(41).end_row();
out.to_string()        // name,age\n"Smith, John",41\n
out.save(new file("people.csv"));
    text := csv_writer.format(rows);      // rows: list<csv_row>

    A field is put in quotes when it contains the separator, a quote, a line end, or starts or ends with a space or tab (so that readers which trim do not change it); a quote inside is written twice. set_always_quote(true) quotes every field.

    Rows end with "\n" unless set_line_end() says otherwise ("\r\n" is what the CSV standard and Excel use).

    The text is collected in memory. Not thread safe.

    def set_quote(ch: decimal) : csv_writer

    Enclose fields with the character ch instead of the double quote. Returns this writer. Throws csv_exception when ch is the separator or a line end.

    class hex

    source

    Hexadecimal: bytes written as two digits each (0-9, a-f), and the classic "hex dump" for looking at binary data.

    hex.encode("Hi!")                 "486921"
hex.decode("486921")              "Hi!"
hex.from_number(255, 4)           "00ff"
hex.to_number("ff")               255
hex.dump("Hello, world! 123")
    00000000  48 65 6c 6c 6f 2c 20 77  6f 72 6c 64 21 20 31 32  |Hello, world! 12|
    00000010  33                                                |3|

    Strings stand for bytes here: every character of the input of encode() and dump() is one byte, and decode() gives a string whose characters are the decoded bytes. The _bytes variants take and give byte arrays.

    Everything is static. Malformed input throws parse_exception.

    Functions

    static def decode(text: string) : string

    The bytes that the hexadecimal text encodes, as a string with one character per byte. Upper and lower case digits are accepted; spaces, tabs, line ends and the characters ':' and '-' between bytes are skipped, so "48 69 21", "48:69:21" and "486921" all work. An optional "0x" at the very beginning is skipped too.

    Throws parse_exception for any other character and for an odd number of digits.

    static def decode_bytes(text: string) : _int8[]?

    the bytes that the hexadecimal text encodes as an array; null when there are none. Accepts and throws like decode().

    static def dump(data: string) : string

    A hex dump of the bytes of data: 16 bytes per line, each line with the offset of its first byte (8 hexadecimal digits), the bytes as two digits each (an extra space after the eighth), and the same bytes as text between '|' - printable ASCII as it is, everything else as '.'. Every line ends with "\n". "" gives "".

    static def dump_bytes(bytes: _int8[]?) : string

    a hex dump of bytes (see dump()); null gives ""

    static def encode(data: string) : string

    the bytes of data (one per character) as lower case hexadecimal, two digits per byte; "" gives ""

    static def encode_bytes(bytes: _int8[]?) : string

    bytes as lower case hexadecimal; null gives ""

    static def encode_separated(data: string, separator: decimal) : string

    The bytes of data as lower case hexadecimal with the character separator between the bytes: encode_separated("Hi!", ':') gives "48:69:21" (the way network addresses and fingerprints are written).

    static def encode_upper(data: string) : string

    the bytes of data as upper case hexadecimal

    static def from_number(value: decimal, min_digits: decimal) : string

    A whole number from 0 to 2^53 in lower case hexadecimal, padded with zeros on the left to at least min_digits digits (0 for no padding): from_number(255, 0) is "ff", from_number(255, 4) is "00ff". Throws illegal_argument_exception for a negative number.

    static def is_valid(text: string) : bool

    true when decode(text) would succeed

    static def to_number(text: string) : decimal

    The value of a hexadecimal number: "ff", "FF" and "0xff" give 255. Exact up to 2^53 (13 digits and a bit). Throws parse_exception for "", for other characters, and for more than 16 digits.

    class ini_file

    source

    Settings in the INI format: sections with "key = value" lines.

    ; comment
name = demo
    [server]
host = localhost
port = 8080
debug = yes
    config := ini_file.load(new file("app.ini"));
host := config.value_or("server", "host", "127.0.0.1");
port := config.number_or("server", "port", 80);
if(config.bool_or("server", "debug", false)) { ... }
config.put("server", "port", "9090");
config.save(new file("app.ini"));

    The format as it is read: - "[name]" starts a section; entries before the first one belong to the section "" (the global section) - "key = value" (or "key: value") is an entry; white space around key and value is removed; the value may be empty and may contain '=' - a value in double quotes keeps its spaces, and \" \\ \n \t inside it are escapes: path = " C:\\dir " - lines starting with ';' or '#' are comments, empty lines are skipped - a section that appears twice is one section; a key that appears twice keeps the last value - anything else throws parse_exception with the line number: a line without '=' or ':', an entry without a key, "[name" without ']'

    Section names and keys are compared exactly (case matters). Everything is kept in the order it first appeared, and written back in that order. Comments are not kept: save() writes the entries only. Values are strings; number_or() and bool_or() interpret them.

    Not thread safe.

    ini_file()

    settings without any entry

    true when there is a section name ("" is the global section, which exists once it has an entry)

    def keys(name: string) : list<string>

    the keys of the section name in order; an empty list when there is no such section

    static def load(source: file) : ini_file

    The settings in the file source. Throws io_exception when the file does not exist or is a directory, parse_exception for a malformed line.

    def number_or(section_name: string, key: string, fallback: decimal) : decimal

    The value of key in the section section_name as a number, or fallback when the entry does not exist. Throws number_format_exception when the entry exists but is not a number ("12", "-0.5", "1e3" are; "", "abc", "12px" are not).

    static def parse(text: string) : ini_file

    The settings in the INI text text. Throws parse_exception for a malformed line.

    def put(section_name: string, key: string, value: string) : ini_file

    Set key in the section section_name to value, creating the section when needed. Returns these settings so calls can be chained. Throws illegal_argument_exception when the key is empty or contains '=', ':' or a line end, starts with '[', ';' or '#', or when the section name contains ']' or a line end (such entries could not be read back).

    def put_bool(section_name: string, key: string, value: bool) : ini_file

    set key in the section section_name to "true" or "false". Returns these settings. Throws like put().

    def put_number(section_name: string, key: string, value: decimal) : ini_file

    set key in the section section_name to a number, written the short way ("8080", "0.5"). Returns these settings. Throws like put().

    def read_text(text: string)

    Add the entries of the INI text text to these settings (entries that exist already are replaced). Throws parse_exception for a malformed line; the entries of the lines before it have been added then.

    def remove(section_name: string, key: string) : bool

    remove key from the section section_name; returns true when there was such an entry. An emptied section stays.

    def remove_section(name: string) : bool

    def save(target: file)

    Replace the content of the file target with to_string(). Throws io_exception when the file cannot be written.

    def section(name: string) : ini_section?

    the section name with its entries, or null when there is none. Changing the section changes these settings.

    def sections() : list<string>

    the names of all sections in order ("" for the global section, when it has entries)

    the number of entries in all sections together

    override def to_string() : string?

    The settings as INI text: the global entries first, then every section as "[name]" followed by its "key = value" lines, with an empty line between sections. Values that need it are written in double quotes. parse() of this text gives the same settings.

    def value_or(section_name: string, key: string, fallback: string) : string

    class ini_section

    source

    class json

    source

    JSON AND YOUR OWN CLASSES

    class address { street : string = ""; city : string = ""; }
    class user {
    name : string = "";
    age : _int64 = 0;
    admin : bool = false;
    home : address?;
    tags : list<string> = new list<string>();
    photo_url : string?;
}
    someone := json.to<user>("{\"name\":\"ann\",\"age\":31,\"home\":{\"city\":\"Oslo\"},\"tags\":[\"a\",\"b\"]}");
someone.home!!.city                     // "Oslo"
    everyone := json.to<list<user> >(text);     // a json array
text := json.of(someone);                   // {"name":"ann","age":31,"admin":false, ...}

    A json object fills an object FIELD BY FIELD, by name. Nothing is written per class: no annotations, no from_json().

    json                field
"text"              string
12, 1.5             any number type (_int64, decimal, int, long, double ...); "12" in quotes is read too
true, false         bool, boolean
{ ... }             a class of yours - filled the same way, as deep as it goes
[ ... ]             list<T>, T[] (T any of the above), a number array (_int64[], decimal[] ...)
"text"              _int8[]: the characters (and json.of writes an _int8[] as a text)
anything            json_value: the value as it is, for parts without a fixed shape
null, or missing    the field keeps what its constructor gave it

    NAMES. A member is looked for under the field's name, and then under the name as most web APIs write it: the field photo_url is filled by "photo_url" or by "photoUrl". Members no field has are skipped. json.of() writes the field's name as it is.

    WHAT A CLASS NEEDS: a constructor without parameters (which every class without a written constructor has). It runs first, so a field's written value is what stays when the json does not mention it.

    NOT READ YET: enums, hash maps (declare such a part as json_value), and fields of the type object. json.of() writes an enum as its name.

    A value of the wrong kind - a text where the field is a number, an array where it is an object - is a json_exception that says where: "user.home.city: expected a string, found a number".

    json.to<t>(text)            an object of t from json text
json.value_to<t>(value)     ... from a json_value that is parsed already
json.fill(object, value)    fill an object you made
json.of(object)             json text of an object, a list or an array
json.value_of(object)       ... as a json_value
json.pretty(object)         ... as text over several lines
json.parse(text)            a json_value (the same as json_parser.parse)

    How it is done: std.reflect (reflect.sharp).

    Java comparison: Gson's gson.fromJson(text, User.class) and toJson(user);
Kotlin: Json.decodeFromString<User>(text).

    class json_exception

    base exception · source

    Thrown by the JSON classes: by json_parser for text that is not valid JSON, by json_value when a value is used as something it is not (asking a string for its number, a missing member, an index outside an array), and by json_writer for a number JSON cannot express (NaN, infinity).

    For a parse error the place is recorded: position is the index of the offending character in the text (from 0), line and column count from 1. The message already contains them, e.g.

    expected ',' or '}' but found ']' at line 3, column 14

    For the other errors all three are -1.

    Fields

    positiondecimalindex in the text of the character that is wrong (from 0), or -1 when the error is not about text
    linedecimalline of that character, counting from 1, or -1
    columndecimalplace of that character in its line, counting from 1, or -1

    class json_parser

    source

    Turns JSON text into a json_value.

    doc := json_parser.parse("{\"ok\": true, \"items\": [1, 2, 3]}");
doc := json_parser.parse_file(new file("config.json"));

    The whole of JSON (RFC 8259) is accepted and nothing else: - objects, arrays, strings, numbers, true, false, null, nested in any way - string escapes: \" \\ \/ \b \f \n \r \t and \uXXXX. Strings in this language are sequences of bytes, so a \uXXXX character is stored as its UTF-8 bytes (1 to 4 of them; two escapes that form a surrogate pair give one character). Characters that are written directly in the text are kept byte for byte. - white space (space, tab, line ends) between the parts - an object that names a member twice keeps the last value

    Not accepted, as the standard says: comments, a comma after the last element, single quotes, numbers like 01 / .5 / +1 / 1. / NaN, line breaks and other control characters inside strings, a \u escape that is half of a surrogate pair, and anything but white space after the value.

    Text that is not valid JSON throws json_exception. Its message says what was expected, what was found and where (line and column from 1); the exception also carries position, line and column as numbers.

    The parser does not use recursion: nesting depth is limited only by set_max_depth() (1000 levels by default), which exists so that a hostile text of a million '[' cannot use up the memory.

    parse() and parse_file() are static shortcuts; make a json_parser object to change the depth limit. A parser object can be used again and again. Not thread safe.

    class json_value

    source

    One JSON value: null, a boolean, a number, a string, an array of values or an object (names with values). A whole JSON document is a json_value whose arrays and objects hold more json_values.

    Reading:

    doc := json_parser.parse("{\"name\": \"Ada\", \"tags\": [\"a\", \"b\"], \"age\": 36}");
name := doc.member("name").as_string();          // "Ada"
age := doc.number_or("age", 0);                  // 36
second := doc.member("tags").at(1).as_string();  // "b"
missing := doc.find("email");                    // null

    Building:

    doc := json_value.new_object();
doc.put_string("name", "Ada").put_number("age", 36);
tags := json_value.new_array();
tags.add_string("a").add_string("b");
doc.put("tags", tags);
text := doc.to_string();     // {"name":"Ada","age":36,"tags":["a","b"]}

    One class is used for all six kinds; kind() / is_...() tell which one a value is. Using a value as the wrong kind (as_number() on a string, at() on an object, ...) throws json_exception.

    Objects keep their members in the order they were added, and a name occurs only once: putting a name again replaces its value.

    The names an object hands out (key_at(), keys()) are COPIES: strings can be changed in place, and the stored name may be shared with other objects of the same document (the parser makes each name once).

    Numbers are native numbers (decimal): whole numbers are exact up to 2^53.

    Arrays and objects are changed in place and are shared, not copied, when put into another value (deep_copy() makes an independent copy). Do not put a value into itself: writing or comparing such a structure never ends. Not thread safe.

    (get and set are keywords of the language, which is why the functions are called at / member / find and put / put_at.)

    class json_writer

    source

    Turns a json_value into JSON text.

    json_writer.to_compact(doc)        {"name":"Ada","tags":["a","b"]}

    Options (all off by default): - set_indent(n): n > 0 writes for people - every member and element on its own line, n spaces per level, a space after each colon; empty arrays and objects stay "[]" and "{}". 0 writes compact text without any white space. - set_sort_keys(true): members are written sorted by name instead of in the order they were added, so equal objects give equal text. - set_ascii_only(true): characters outside ASCII are written as \uXXXX escapes (the bytes of the string are read as UTF-8), so the text survives any channel.     Percent encoding for URLs, and building and taking apart query strings.

    url_codec.encode("a b&c=d/e")          "a%20b%26c%3Dd%2Fe"

    Percent encoding (RFC 3986): letters, digits and - . _ ~ are written as they are, every other byte as '%' and two hexadecimal digits. Strings are sequences of bytes, so a character outside ASCII is encoded byte by byte (text in UTF-8 gives the usual result, e.g. "%C3%A9").

    The "form" variants are for query strings and HTML form data (application/x-www-form-urlencoded): a space is written as '+', and '+' is read as a space.

    A query string keeps its pairs in order and may repeat a key, so pairs are passed as two lists of the same length (keys and values) rather than a map.

    Everything is static. Malformed input ('%' without two hexadecimal digits) throws parse_exception.

    static def encode(text: string) : string

    static def encode_path(text: string) : string

    static def parse_query(query: string, keys: list<string>, values: list<string>) : decimal

    def attribute(name: string, value: string) : xml_writer

    Add an attribute to the element that was just started: writes name="value" with the value escaped. Returns this writer. Throws illegal_state_exception when no start tag is open (content was already written, or no element was started) or the element has this attribute already; illegal_argument_exception for an invalid name or a value with a character XML does not allow.

    def attribute_number(name: string, value: decimal) : xml_writer

    add an attribute whose value is a number, written the short way ("3", "0.5"). Returns this writer. Throws like attribute().

    def cdata(content: string) : xml_writer

    Add text to the innermost open element as a CDATA section, in which nothing needs escaping: <![CDATA[ ... ]]>. Handy for text full of < and &, like code. The one sequence a CDATA section cannot contain, "]]>", is split over two sections. Returns this writer. Throws illegal_state_exception when no element is open.

    def comment(content: string) : xml_writer

    Add a comment: <!-- content -->. Allowed anywhere, also before and after the root element. Returns this writer. Throws illegal_argument_exception when the content contains "--" or ends with "-" (XML does not allow that in a comment).

    def declaration() : xml_writer

    Write the XML declaration <?xml version="1.0" encoding="UTF-8"?>. It has to be the very first thing. Throws illegal_state_exception when something was written already.

    def depth() : decimal

    how many elements are open at the moment

    def element(name: string, content: string) : xml_writer

    a whole element with text and nothing else: start(name), text(content), end(). Returns this writer. Throws like those.

    def end() : xml_writer

    Close the innermost open element: writes </name>, or turns an element without content into <name/>. Returns this writer. Throws illegal_state_exception when no element is open.

    def end_all() : xml_writer

    close all elements that are still open. Returns this writer.

    static def escape(content: string) : string

    the text of content with & < > escaped, as it would appear between tags: escape("a<b") gives "a&lt;b"

    def save(target: file)

    Replace the content of the file target with the finished document. Throws illegal_state_exception like to_string(), io_exception when the file cannot be written.

    def set_indent(spaces: decimal) : xml_writer

    Indent nested elements by spaces spaces per level and put them on lines of their own (0 = everything in one line). Call it before writing anything. Returns this writer. Throws illegal_argument_exception when spaces is negative.

    def start(name: string) : xml_writer

    Open an element: writes <name. Attributes can be added until content follows. Returns this writer. Throws illegal_argument_exception for an invalid name and illegal_state_exception for a second root element.

    def text(content: string) : xml_writer

    Add text to the innermost open element, escaped. Empty text adds nothing. Returns this writer. Throws illegal_state_exception when no element is open and illegal_argument_exception for a character XML does not allow.

    override def to_string() : string?

    The finished document as text (with a line end at the end when indenting). Throws illegal_state_exception when elements are still open or no root element was written.
