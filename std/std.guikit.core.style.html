    class modifier

    source

    modifier - how a widget's BOX is changed: its size, the room around it, its background, whether it can be clicked. You chain what you want onto one and PASS IT IN where the widget is made:

    text("Hello", modifier().padding(8))
column(modifier().fill().padding(16)) { ... }
button("Save", modifier().fill_width()) { save(); }
text_field(name, modifier().grow(1))

    This is the ONLY way to change a widget's box. Every widget function takes an optional modifier, and no widget has box settings of its own - so there is one vocabulary, in one place, that works the same on everything:

    room inside      .padding(all)   .padding(sides, top_bottom)   .padding(l, t, r, b)
room outside     .margin(all)    .margin(sides, top_bottom)    .margin(l, t, r, b)
size             .width(n)  .height(n)  .size(w, h)
                 .min_width(n)  .min_height(n)  .max_width(n)  .max_height(n)
                 .fill()  .fill_width()  .fill_height()
                 .grow(share) / .weight(share)     a share of the leftover room
                 .width_part(0.5)  .height_part(0.5)   a fraction of the parent
                 .aspect(16.0 / 9)                     a fixed shape
its own place    .align(how)  in a row or column     .place(across, down)  in a stack
looks            .background(colour)  .corner(radius)  .border(thickness, colour)  .shadow(depth)
looks            .opacity(0.5)
behaviour        .click { ... }  .show(yes)  .visible(yes)  .enable(yes)  .key(name)
gestures         .long_press { }  .double_click { }  .right_click { }
                 .drag { dx, dy -> }  .drag_start { }  .drag_end { }  .tooltip(words)

    (What a widget IS stays with the widget: a text's .size() and .color(), a column's .gap(), a button's .outline(). The modifier is about the box every widget has in common.)

    NAME A LOOK ONCE AND REUSE IT - a modifier is an ordinary value:

    card := modifier().padding(16).background(t.surface).corner(10);
column(card) { ... }
column(card.then(modifier().grow(1))) { ... }      // the card look, plus one more setting

    This is Compose's Modifier, and the reason is the same as there: if every widget had its own padding / size / background parameters, each widget would have to repeat them and they would drift apart. One object that carries them all means a new widget gets every one of them for free. (CSS: a class.)

    HOW IT WORKS: a modifier is a notepad. Each call writes one setting down and hands the same modifier back, so calls chain. Nothing happens until the widget function it is passed to calls apply_to, which copies the settings that were WRITTEN onto the widget's view (view.sharp) - the ones never mentioned leave the view as it was. "Written" is tracked by each field's untouched value (-1 for sizes, null for colours ...), the same untouched values the view itself starts with.

    Functions

    def align(how: _int64) : modifier

    Where THIS child sits across its row or column, whatever the container says for the others: ALIGN_START, ALIGN_CENTER, ALIGN_END, ALIGN_STRETCH. (Android: layout_gravity. Compose: Modifier.align.)

    def animate_size() : modifier

    When the box's height changes (its content grew, something inside was shown or hidden), glide to the new height instead of jumping - and whatever is below it moves along. (Compose: animateContentSize.)

    def apply_to(target: view)

    Copy every setting this modifier mentions onto a widget's view. The widget functions call this; you do not.

    def aspect(width_by_height: decimal) : modifier

    Keep this shape whatever the size: width divided by height. A video thumbnail is aspect(16.0 / 9), a square is aspect(1). The box becomes as wide as it is allowed and exactly as tall as the shape then needs (or the other way round when that would be too tall). (Compose: Modifier.aspectRatio.)

    def at(place: decimal, value: decimal) : modifier

    over place place (0 is the first; 2.5 is between the third and the fourth), at the height of value

    def at_place(place: decimal) : modifier

    over place place, at the top

    def at_value(value: decimal) : modifier

    on the level of value, at the left

    def background(c: color) : modifier

    a background colour behind the widget (padding included)

    def background(c: color, outline: shape) : modifier

    a background colour in a shape: shape.pill(), shape.circle(), shape.star(), your own (shape.sharp)

    def blur(pixels: decimal) : modifier

    blur the widget and everything in it by about this many pixels; 0 is sharp (Compose: Modifier.blur)

    def border(thickness: decimal, c: color) : modifier

    a border line inside the widget's edge

    def click(what: ()()) : modifier

    Run this when the widget is clicked. Works on anything: a text, a picture, a whole row. It also makes the widget reachable with Tab and clickable with Enter.

    row(modifier().click { open(item); }) { ... }

    (Compose: Modifier.clickable. Android: setOnClickListener.)

    def clip(outline: shape) : modifier

    Cut the widget and everything in it to a shape: a round picture is image(path, modifier().size(64, 64).clip(shape.circle())). (Compose: Modifier.clip.)

    def corner(pixels: decimal) : modifier

    round the corners of the background and border

    def double_click(what: ()()) : modifier

    run this when the widget is clicked twice in quick succession (the first click still counts as a click)

    def drag(what: (decimal, decimal)()) : modifier

    Run this while the widget is DRAGGED: pressed, and the mouse moved while held. It is told how far the mouse moved since the last time, across and down, in pixels - add those to a position to make something follow the mouse:

    box(modifier().drag { dx: decimal, dy: decimal -> x.value += dx; y.value += dy; })

    A drag does not also count as a click. .drag_start { } and .drag_end { } tell you when one begins and ends. (Compose: Modifier.draggable / detectDragGestures. Android: onTouchEvent with ACTION_MOVE.)

    def drag_end(what: ()()) : modifier

    run this when a drag of the widget ends (the button came back up)

    def drag_start(what: ()()) : modifier

    run this when a drag of the widget begins

    def enable(yes: _int64) : modifier

    can it be clicked and focused? enable(0) greys it out. enable(agreed.value)

    def fill() : modifier

    take all the room the parent offers, both ways

    def fill_height() : modifier

    take all the height the parent offers

    def fill_width() : modifier

    take all the width the parent offers

    def grow(share: decimal) : modifier

    Inside a row or column: take a share of the room that is LEFT OVER after the other children have what they need. Two children with grow(1) split it evenly; grow(2) next to grow(1) gets twice as much. (CSS: flex-grow. Compose: Modifier.weight.)

    def height(pixels: decimal) : modifier

    exactly this tall

    def height_part(fraction: decimal) : modifier

    this fraction of the parent's height

    def key(id: string) : modifier
    def long_press(what: ()()) : modifier

    Run this when the widget is pressed and HELD for about half a second without moving. A long press does not also count as a click. (Android: setOnLongClickListener. Compose: combinedClickable(onLongClick).)

    def margin(all: decimal) : modifier

    Room OUTSIDE the box, between it and its neighbours - the same on all four sides. (Padding is room INSIDE the box: the background covers the padding but not the margin, and a click in the margin misses the box.) (Android: layout_margin. CSS: margin.)

    def margin(sides: decimal, top_bottom: decimal) : modifier

    margin left+right, and top+bottom

    def margin(left: decimal, top: decimal, right: decimal, bottom: decimal) : modifier

    margin per side, clockwise from the left: left, top, right, bottom

    def max_height(pixels: decimal) : modifier

    never taller than this

    def max_width(pixels: decimal) : modifier

    never wider than this (text wraps to it)

    def min_height(pixels: decimal) : modifier

    never shorter than this

    def min_width(pixels: decimal) : modifier

    never narrower than this

    def opacity(amount: decimal) : modifier

    How solid the widget and everything in it is painted: 1 fully (the default), 0.5 half see-through, 0 not at all (it still takes its room). (Compose: Modifier.alpha. CSS: opacity.)

    def padding(all: decimal) : modifier

    the same padding on all four sides

    def padding(sides: decimal, top_bottom: decimal) : modifier

    padding left+right, and top+bottom

    def padding(left: decimal, top: decimal, right: decimal, bottom: decimal) : modifier

    padding per side, clockwise from the left: left, top, right, bottom

    def place(across: _int64, down: _int64) : modifier

    Where THIS child sits in a stack: across (ALIGN_START left, _CENTER, _END right) and down (top, center, bottom). modifier().place(ALIGN_END, ALIGN_END) is the bottom-right corner.

    def right_click(what: ()()) : modifier

    run this when the widget is clicked with the RIGHT mouse button: the usual way to open a context menu

    def rotate(degrees: decimal) : modifier

    Turn the widget - with everything in it - this many degrees clockwise around its middle. Only how it is PAINTED changes: it keeps the room layout gave it, and the mouse still finds it where it would be unturned. (Compose: Modifier.rotate / graphicsLayer.)

    def scale(factor: decimal) : modifier

    paint the widget this many times its size, around its middle: 1.2 a fifth bigger, 0.5 half (Compose: Modifier.scale)

    def shadow(pixels: decimal) : modifier

    A soft shadow under the box, this many pixels deep, so it looks lifted off the page: a card is about 6, a dialog about 14. Give the box a background too - a shadow under nothing looks odd. (Android: elevation. CSS: box-shadow.)

    def shape(outline: shape) : modifier

    the shape of the background and border, when the colour is set elsewhere (a card's own surface)

    def show(yes: _int64) : modifier

    show it or not: show(0) takes NO ROOM and paints nothing. show(logged_in.value) (Android: GONE)

    def size(w: decimal, h: decimal) : modifier

    exactly this big

    def tag(name_for_tests: string) : modifier

    A name for UI tests to find this widget by (std.guikit.testing):

    button("Save", modifier().tag("save")) { ... };
// in a test:
on_tag("save").click();

    Every widget takes it, and it changes nothing about how the widget looks or works. Words on the screen change with the language and the wording; a tag stays. (Android: Modifier.testTag.)

    def then(more: modifier) : modifier

    A NEW modifier with everything this one says, and then everything more says - where both mention the same thing, more wins. Neither of the two is changed, so a named look stays reusable:

    card.then(modifier().grow(1))
    def tooltip(words: string) : modifier

    words shown in a small box when the mouse rests on the widget for a moment

    def visible(yes: _int64) : modifier

    visible(0) paints nothing and cannot be clicked, but KEEPS ITS ROOM, so the things around it do not move. Use it when a part of the screen should blink in and out without the layout jumping. (Android: INVISIBLE)

    def weight(share: decimal) : modifier

    the same as grow(share), under the name Android and Compose use

    def width(pixels: decimal) : modifier

    exactly this wide

    def width_part(fraction: decimal) : modifier

    This fraction of the parent's width: width_part(0.5) is half, however wide the parent turns out to be. Always a fraction of the WHOLE parent, so two children with 0.5 are the same width. (Android: ConstraintLayout's layout_constraintWidth_percent.)

    class shape

    source

    shape - the outline of a box: what its background is filled as, and what its content is cut to.

    modifier().background(t.surface, shape.rounded(12))
modifier().background(t.primary, shape.pill())
modifier().background(t.success, shape.circle())
modifier().background(gold, shape.star())
modifier().clip(shape.circle())                     // a round picture

    A shape has no size of its own: it is stretched over whatever box it is given. So the same shape.pill() is right for a small chip and a wide bar.

    YOUR OWN SHAPE is a list of corners, each given as a fraction of the box (0, 0 is the top left; 1, 1 the bottom right), in order around the shape:

    arrow := shape.corners { p: shape_path ->
    p.to(0, 0.3); p.to(0.6, 0.3); p.to(0.6, 0); p.to(1, 0.5);
    p.to(0.6, 1); p.to(0.6, 0.7); p.to(0, 0.7);
};

    Make a shape once and keep it (a field, a global): it is the same object every time it is used.

    What works with what, today: background every shape border rounded, pill, circle clip rounded, pill, circle (a shape with corners clips to its box)

    (Compose: Shape - RoundedCornerShape, CircleShape, GenericShape. Android: ShapeDrawable, MaterialShapeDrawable.)

    class theme

    source

    theme - the colours and sizes every built-in widget draws itself with.

    Widgets never hard-code a colour: a button asks the theme for primary, a label for text. Change the theme and the whole app changes with it:

    gui.use_theme(theme.light());          // before gui.run(...)
    mine := theme.dark();                  // or start from one and adjust
mine.primary = gui.rgb(255, 120, 60);
gui.use_theme(mine);

    A widget can still be given its own colour with a modifier (.background(c), text .color(c)); the theme is only the default. Android comparison: a Theme / Material colour scheme. CSS: custom properties on :root.
