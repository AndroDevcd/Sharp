    class bit_flags

    source

    A small set of on/off options packed into one number, one bit per option. Define the options as powers of two and combine them with add():

    const READ : decimal = 1;       // bit_flags.flag(0)
const WRITE : decimal = 2;      // bit_flags.flag(1)
const EXECUTE : decimal = 4;    // bit_flags.flag(2)
    access := new bit_flags(READ);
access.add(WRITE);
access.has(WRITE).value         // true
access.has(READ + EXECUTE).value    // false: not ALL of them are set
access.has_any(READ + EXECUTE)    // true: one of them is
access.value                    // 3, e.g. to store in a file

    A "mask" is any combination of flags (their sum, as long as each flag appears once). Up to 32 flags are supported: masks are whole numbers in 0 .. 4294967295. Unlike most classes in this library a bit_flags object is MUTABLE: add / remove / toggle / clear change it (and return it, so calls can be chained).

    Every method throws illegal_argument_exception for a mask that is negative, fractional or above 4294967295.

    Fields

    valuedecimalall flags that are currently set, as one number (read only; use add / remove / assign)

    Functions

    no flag set

    the flags of mask set

    def add(mask: decimal): bit_flags

    switch on every flag of mask; flags that are already on stay on

    def assign(mask: decimal, enabled: bool): bit_flags

    switch the flags of mask on (enabled true) or off (enabled false)

    def clear(): bit_flags

    switch every flag off

    def copy_of(): bit_flags

    an independent copy of this set

    def count(): decimal

    how many flags are on

    static def flag(position: decimal): decimal

    The mask for flag number position (0 .. 31): 2^position, so flag(0) == 1, flag(1) == 2, flag(5) == 32. Throws illegal_argument_exception for any other position.

    def has(mask: decimal): bool

    true when ALL flags of mask are on (true for the empty mask 0)

    def has_any(mask: decimal): bool

    true when AT LEAST ONE flag of mask is on (false for the empty mask 0)

    def has_none(mask: decimal): bool

    true when NO flag of mask is on

    override def hash(): int

    the hash code is the mask itself (equal sets have equal hashes)

    def intersection(other: bit_flags): bit_flags

    a new set with the flags that are on in this set AND in other

    def is_empty(): bool

    true when no flag at all is on

    def operator!=(other: bit_flags): bool

    true when the sets differ in at least one flag

    def operator==(other: bit_flags): bool

    true when both sets have exactly the same flags on

    def remove(mask: decimal): bit_flags

    switch off every flag of mask; flags that are already off stay off

    override def to_string(): string?

    The flags as binary digits, the highest set flag first: a set with flags 0 and 2 on is "101"; the empty set is "0".

    def toggle(mask: decimal): bit_flags

    flip every flag of mask: on becomes off, off becomes on

    def union_with(other: bit_flags): bit_flags

    a new set with the flags that are on in this set OR in other

    class comparator<T>

    source

    An ordering for objects of type T: something that can say which of two objects comes first. Comparators are built from small pieces and combined (Java's Comparator, Kotlin's compareBy / thenBy / reversed):

    by_age := comparator<person>.by_key({ p: person -> (decimal) return p.age; });
by_name := comparator<person>.by_text({ p: person -> (string) return p.name; });
    oldest_first := by_age.reversed();
by_age_then_name := by_age.then_by(by_name);
    by_age_then_name.sort(people);          // sorts the array in place
youngest := by_age.min_of(people);

    compare(a, b) follows the usual convention: a NEGATIVE number when a comes before b, a POSITIVE number when a comes after b, 0 when the order does not distinguish them.

    A comparator never changes after it is made; reversed() and then_by() return new comparators. The class std.util#comparators has ready-made comparators for strings and the number classes.

    LIMITATION: T must be an object type.

    Functions

    comparator(compare_function: (T, T)(decimal))

    A comparator from a function that returns a negative number, 0 or a positive number for "a before b", "same" and "a after b".

    def binary_search(items: T[], wanted: T): decimal

    Find wanted in an array that is SORTED by this ordering, by halving the search interval: O(log n). Returns the index of an element that compares equal to wanted, or -1 when there is none.

    static def by_key(key: (T)(decimal)): comparator<T>

    Order objects by a number taken from each: the object with the smaller key comes first (Kotlin compareBy).

    static def by_text(key: (T)(string)): comparator<T>

    Order objects by a text taken from each, compared character by character by character code ("Zebra" comes before "apple"; a text comes after its own prefixes).

    def compare(a: T, b: T): decimal

    Compare two objects: negative when a comes before b, positive when a comes after b, 0 when this ordering does not distinguish them.

    static def compare_text(a: string, b: string): decimal

    Compare two texts character by character by character code: negative when a comes first, positive when b comes first, 0 when they are equal. A text that is a prefix of the other comes first.

    def in_order(a: T, b: T): bool

    true when a and b are in order or equal: compare(a, b) <= 0

    def is_sorted(items: T[]): bool

    true when every element is in order with the one after it (also for 0 or 1 elements)

    def max_of(items: T[]): T

    The element that comes last in this ordering (the last of several equal ones). Throws no_such_element_exception when the array is empty.

    def min_of(items: T[]): T

    The element that comes first in this ordering (the first of several equal ones). Throws no_such_element_exception when the array is empty.

    def reversed(): comparator<T>

    the opposite ordering: what came first now comes last

    def sort(items: T[])

    Sort the array in place, smallest first according to this ordering.

    Algorithm: bottom-up merge sort (no recursion) with one helper array. O(n log n) comparisons and STABLE: objects the ordering calls equal keep their original relative order, which is what makes sorting by one key and then by another work.

    def sort(items: list<T>)

    sort a list in place (see sort for arrays); does nothing for an empty list

    def then_by(other: comparator<T>): comparator<T>

    This ordering, with other deciding between objects this one calls equal (sort by last name, then by first name).

    def then_by_key(key: (T)(decimal)): comparator<T>

    then_by(by_key(key)): ties are decided by a number taken from each object

    def then_by_text(key: (T)(string)): comparator<T>

    then_by(by_text(key)): ties are decided by a text taken from each object

    class counter

    source

    A number in an object: something to count with that can be shared.

    A lambda can use the objects around it but cannot assign to an outer native variable, so total += x inside a lambda does not work on a decimal. A counter is an object, so this does:

    seen := new counter();
items.for_each({ item: string -> seen.increment(); });
println("" + seen.value);

    It is also handy as a tally that several functions update, or as a running total (add() takes any number, not only 1).

    value is a public field and may be read or assigned directly. The class does no locking; guard it when several threads count together.

    class either<L, R>

    source

    A value that is ONE of two types: a "left" of type L or a "right" of type R. By convention the right side is the good result and the left side the alternative (usually an error description), which makes either the complement of std#result: a result always has data and maybe an error, an either has exactly one of the two.

    def parse_port(text: string): either<string, int> {
    if(text.size() == 0) return either<string, int>.left("empty");
    return either<string, int>.right(8080);
}
    answer := parse_port("x");
if(answer.is_right()) use(answer.right_value());
else println(answer.left_value());

    An either never changes after it is made.

    LIMITATION: L and R must be object types (the two sides are stored in nullable fields), and neither side may hold null.

    Functions

    def if_left(action: (L)())

    call action with the left value; does nothing for a right value

    def if_right(action: (R)())

    call action with the right value; does nothing for a left value

    def is_left(): bool

    true when the left side is held

    def is_right(): bool

    true when the right side is held

    static def left(value: L): either<L, R>

    An either holding a left value. Throws illegal_argument_exception when value is null.

    def left_or(fallback: L): L

    the left value, or fallback when this either holds a right value

    def left_or_null(): L?

    the left value, or null when this either holds a right value

    def left_value(): L

    The left value. Throws no_such_element_exception when this either holds a right value.

    def map_left(transform: (L)(L)): either<L, R>

    Apply transform to the left value; a right value is passed through untouched (the function is not called).

    def map_right(transform: (R)(R)): either<L, R>

    Apply transform to the right value; a left value is passed through untouched (the function is not called).

    static def right(value: R): either<L, R>

    An either holding a right value. Throws illegal_argument_exception when value is null.

    def right_or(fallback: R): R

    the right value, or fallback when this either holds a left value

    def right_or_null(): R?

    the right value, or null when this either holds a left value

    def right_value(): R

    The right value. Throws no_such_element_exception when this either holds a left value.

    class hashing

    source

    Well-known 32-bit hash and checksum functions over text and bytes. Only static functions; never instantiated.

    hashing.fnv1a("hello")              // 1335831723
hashing.crc32("123456789")          // 3421780262 (0xCBF43926)
hashing.to_hex(hashing.crc32("123456789"))      // "cbf43926"
code : decimal = hashing.combine(name_hash, age);   // a hash for an object with two fields

    Which one to use:

    fnv1a     hash tables and general purpose hashing: fast, spreads well
djb2      the classic "times 33" string hash; simple, common in older code
crc32     detecting accidental changes (files, network packets); the
          same polynomial as zip, gzip, png and Ethernet
adler32   a cheaper but weaker checksum (zlib)

    None of these is cryptographic: it is easy to construct two inputs with the same result on purpose. Do not use them for passwords or signatures.

    All results are whole numbers in 0 .. 4294967295 (an unsigned 32-bit word) and are the same on every machine. Every function exists for a string and for a byte array (_int8[]); characters above 127 are treated as the unsigned bytes 128 .. 255, so a string and its bytes hash the same.

    Native numbers are 64-bit floats, exact up to 2^53, so two 32-bit words cannot simply be multiplied: multiply() below does the multiplication modulo 2^32 in 16-bit halves.

    Functions

    static def adler32(data: _int8[]?): decimal

    Adler-32 (the checksum of zlib). Two running sums modulo 65521: a = 1 + the sum of all bytes, b = the sum of all values a has had. The result is b * 65536 + a. The checksum of no bytes is 1.

    static def adler32(text: string): decimal

    Adler-32 of the characters of a text (see adler32 for bytes); 1 for ""

    static def combine(seed: decimal, value: decimal): decimal

    Mix a further value into a hash code, for hashing an object field by field: start with seed 17 (or any number) and combine every field in.

    code : decimal = hashing.combine(hashing.combine(17, x), y);

    Formula: (seed * 31 + value) modulo 2^32, the scheme of Java's Objects.hash. value may be any whole number; its sign is dropped and it is reduced modulo 2^32 first. The order of the values matters.

    static def combine_all(values: decimal[]): decimal

    combine() over all values of an array, starting from 17; 17 for an empty array

    static def crc32(data: _int8[]?): decimal

    CRC-32 (the checksum of zip, gzip, png, Ethernet; "CRC-32/ISO-HDLC").

    Start with all 32 bits set; every byte is XORed into the low 8 bits, which then pick the next state from a table of 256 numbers (what eight rounds of "shift right, XOR with 0xEDB88320 when a 1 fell out" give); finally all bits are inverted. The CRC of no bytes is 0; the CRC of "123456789" is 0xCBF43926.

    static def crc32(text: string): decimal

    CRC-32 of the characters of a text (see crc32 for bytes); 0 for ""

    static def djb2(data: _int8[]): decimal

    djb2 (Daniel J. Bernstein): start with 5381; for every byte hash = hash * 33 + byte (modulo 2^32). The hash of no bytes is 5381.

    static def djb2(text: string): decimal

    djb2 of the characters of a text (see djb2 for bytes); 5381 for ""

    static def fnv1a(data: _int8[]): decimal

    FNV-1a (Fowler-Noll-Vo), 32 bit. Start with the offset basis 2166136261; for every byte: XOR the byte in, then multiply by the FNV prime 16777619 (modulo 2^32). The hash of no bytes is 2166136261.

    static def fnv1a(text: string): decimal

    FNV-1a of the characters of a text (see fnv1a for bytes); 2166136261 for ""

    static def multiply(a: decimal, b: decimal): decimal

    (a * b) modulo 2^32 for two words in 0 .. 4294967295, exactly.

    With a = ah * 2^16 + al and b = bh * 2^16 + bl: a * b = ah bh 2^32 + (ah bl + al bh) 2^16 + al bl The first term vanishes modulo 2^32, and of the middle term only the low 16 bits survive the shift, so every intermediate value stays below 2^34.

    static def to_hex(word: decimal): string

    A 32-bit word as 8 lowercase hexadecimal digits, with leading zeros: to_hex(255) is "000000ff", to_hex(3421780262) is "cbf43926". Throws illegal_argument_exception when the value is not a whole number in 0 .. 4294967295.

    class id_generator

    source

    Hands out identifiers that are unique within one generator: 1, 2, 3 ... or, with a prefix, "order-1", "order-2" ...

    ids := new id_generator();
first : decimal = ids.next_id();            // 1
second : decimal = ids.next_id();           // 2
    tickets := new id_generator("T-", 1000);
name := tickets.next_text();            // "T-1000"

    The sequence is fully predictable (no clock, no random numbers), which makes it suitable for tests and for anything that must be reproducible. For identifiers that must be unique across programs or machines use std.util#uuid instead.

    Ids are whole native numbers; they stay exact up to 2^53. The class does no locking: guard next_id() when several threads share a generator.

    Functions

    id_generator()

    a generator whose first id is 1

    id_generator(first_id: decimal)

    A generator whose first id is first_id. Throws illegal_argument_exception when first_id is not a whole number.

    id_generator(prefix: string, first_id: decimal)

    A generator whose text ids are prefix followed by the number, starting at first_id. Throws illegal_argument_exception when first_id is not a whole number.

    def issued(): decimal

    how many ids have been handed out since the generator was made or reset

    def last_id(): decimal

    the id handed out most recently; first id - 1 when none has been handed out

    def next_id(): decimal

    the next id as a number; every call returns a number one higher than the call before

    def next_text(): string

    the next id as text: the prefix followed by the number ("order-17"). Advances the same sequence as next_id().

    def peek(): decimal

    the id the next call will return, without using it up

    def reset()

    start again from the first id (ids will then repeat)

    class lazy<T>

    source

    A value that is computed the first time it is asked for, and remembered from then on (Kotlin's by lazy). Use it for something expensive that may never be needed: a parsed configuration, a lookup table, a connection.

    table := new lazy<string>({ -> (string) return build_big_table(); });
// nothing has been built yet
text := table.value();      // built now
again := table.value();     // the same object, not built again

    std#deferred_init is the older, thinner version of this class; lazy adds is_initialized(), reset() and a ready-made value.

    The supplier runs at most once (until reset()). If it throws, nothing is remembered and the next value() call runs it again. The class does no locking: when several threads may ask at the same time, guard the call.

    LIMITATION: T must be an object type, and the supplier has to give an object: value() throws for a null.

    Functions

    lazy(supplier: ()(T))

    a lazy value that will be produced by calling supplier

    def is_initialized(): bool

    true when the value has been computed (or was given ready-made)

    static def of_value(value: T): lazy<T>

    A lazy value that is already known (nothing will be computed). Handy when an API wants a lazy<T> and the value happens to be at hand.

    def reset()

    Forget the remembered value: the next value() call runs the supplier again. Does nothing when no value has been computed yet, and nothing for a lazy made with of_value() (it has no supplier to run again).

    def value(): T

    The value: computed by the supplier on the first call, the remembered object on every later call. An exception thrown by the supplier passes through to the caller.

    class optional<T>

    source

    A box that either holds one value or is empty - a way to say "there may be no result" in a return type instead of returning null and hoping the caller checks (Java's Optional, Kotlin's nullable types).

    def find_user(id: decimal): optional<string> {

    name := find_user(7).or_else("nobody");
found := find_user(1);

    An optional never changes after it is made; map() and filter() return new optionals.

    class preconditions

    source

error(...)            "this cannot happen" was reached   -> illegal_state_exception
todo(...)             the code is not written yet        -> not_implemented_error

    class range

    : loopable<decimal> · source

    An arithmetic progression of native numbers: first, first + step, first + 2 * step ... up to and INCLUDING the last value (Kotlin's IntRange / IntProgression).

    foreach(i in new range(1, 5)) { ... }            // 1 2 3 4 5
foreach(i in new range(10, 1, 0 - 3)) { ... }    // 10 7 4 1
foreach(i in range.until(0, 4)) { ... }          // 0 1 2 3
new range(1, 10).contains(7)               // true
new range(1, 10).stepped(2).to_array()           // { 1, 3, 5, 7, 9 }

    A range is a VALUE: it cannot be changed after it is made; reversed() and stepped() return new ranges.

    The end is normalised: last is always a value the range really reaches, so new range(1, 10, 4) has last == 9 (1, 5, 9). A range whose start lies beyond its end in the direction of the step is EMPTY (size 0), e.g. new range(5, 1) - that is not an error, loops over it just do not run.

    Steps and bounds need not be whole numbers (new range(0, 1, 0.25) is 0, 0.25, 0.5, 0.75, 1), but then the usual floating point caveats apply.

    Fields

    firstdecimalthe first value (read only)
    lastdecimalthe last value the range reaches (read only); meaningless when the range is empty
    stepdecimalthe distance between two neighbouring values; never 0, negative for a falling range (read only)

    Functions

    range(first: decimal, last: decimal)

    the range first, first + 1, ... last (empty when first > last)

    range(first: decimal, last: decimal, step: decimal)

    The range first, first + step, ... not going past last. A negative step counts down. Throws illegal_argument_exception when step is 0.

    def at(index: decimal): decimal

    The value at position index (0 is the first): first + index * step. Throws out_of_bounds_exception when index is outside 0 .. size() - 1.

    def contains(value: decimal): bool

    True when value is one of the values of the range: inside the bounds AND on the step grid. new range(1, 9, 2).contains(4) is false.

    static def down_to(first: decimal, last: decimal): range

    the falling range first, first - 1, ... last (Kotlin downTo). Empty when first < last.

    def for_each(action: (decimal)())

    call action with every value, in order

    override def get_elements(): decimal[]?

    The values for a foreach loop: foreach(i in some_range) { ... }. (The loopable interface; the same array as to_array().)

    def index_of(value: decimal): decimal

    The position of value in the range (0 for the first value), or -1 when the range does not contain it.

    static def indices(count: decimal): range

    the range 0 .. count - 1: the valid indexes of something with count elements

    class ref<T>

    source

    A mutable holder for one object: a variable you can pass around.

    Its main use is with lambdas. A closure can read and call the objects around it but cannot assign to an outer variable; put the value in a ref and the closure can change what the ref holds:

    longest := new ref<string>("");
words.for_each({ w: string -> if(w.size() > longest.value.size()) longest.value = w; });
println(longest.value);

    It also serves as an "out parameter": a function that needs to hand back a second result can fill a ref the caller passed in.

    value is a public field: read and assign it directly.

    LIMITATION: T must be an object type. For a native number use std.util#counter, which is the same idea for a decimal.

    class uuid

    source

    A universally unique identifier: 128 bits, written as 32 hexadecimal digits in five groups, 8-4-4-4-12:

    123e4567-e89b-42d3-a456-426614174000
    id := uuid.random();                    // a new random (version 4) id
text := id.to_string();
same := uuid.parse(text);
(id == same).value                      // true

    VERSION 4 LAYOUT (RFC 4122 / RFC 9562). 122 of the 128 bits are random; six are fixed and mark the kind of uuid:

    xxxxxxxx-xxxx-4xxx-Vxxx-xxxxxxxxxxxx
              ^    ^
              |    variant: the top two bits of byte 8 are 1 0, so V is 8, 9, a or b
              version: the top four bits of byte 6 are 0100

    random() takes its bits from the runtime's random generator (std#rand, seeded from the clock unless set_seed() was called); random(generator) takes them from a std#seeded_random and is fully reproducible. Neither source is cryptographically secure: the ids are fine as database keys and correlation ids but must not be used as secrets (session tokens, password reset links).

    A uuid is a VALUE and cannot be changed after it is made.

    Functions

    def compare_to(other: uuid): decimal

    Three-way comparison, byte by byte from the most significant: -1, 0 or 1. This is the same order as comparing the text forms.

    static def from_bytes(values: decimal[]): uuid

    A uuid from its 16 bytes, most significant first; the array is copied. Throws illegal_argument_exception when the array does not hold exactly 16 whole numbers in 0 .. 255.

    override def hash(): int

    a hash code over all 16 bytes (equal uuids have equal hashes)

    def is_nil(): bool

    true for the nil uuid (all bits zero)

    static def is_valid(text: string): bool

    true when parse(text) would succeed

    static def nil_uuid(): uuid

    the "nil" uuid: all 128 bits zero, 00000000-0000-0000-0000-000000000000

    def operator!=(other: uuid): bool

    true when at least one bit differs

    def operator<(other: uuid): bool

    true when this uuid sorts before other

    def operator==(other: uuid): bool

    true when all 128 bits are equal

    def operator>(other: uuid): bool

    true when this uuid sorts after other

    static def parse(text: string): uuid

    Read a uuid from its text form: 36 characters, hexadecimal digits in groups of 8-4-4-4-12 separated by "-". Capital and small letters are both accepted. Any version is accepted, not only version 4.

    Throws parse_exception for anything else.

    static def parse_or_null(text: string): uuid?

    like parse(), but returns null instead of throwing when the text is not a uuid

    static def random(): uuid

    a new random version 4 uuid from the runtime's random generator

    static def random(generator: seeded_random): uuid

    A new random version 4 uuid whose bits come from generator: the same seed gives the same sequence of uuids.

    def to_bytes(): decimal[]

    a copy of the 16 bytes, most significant first

    override def to_string(): string?

    the text form in small letters: "123e4567-e89b-42d3-a456-426614174000"

    def variant(): decimal

    The variant: 2 for the standard layout of RFC 4122 (top bits of byte 8 are "10"), 0 for the old NCS layout ("0x"), 6 for Microsoft GUIDs ("110") and 7 for the reserved pattern ("111").

    def version_number(): decimal

    the version number 0 .. 15: the top four bits of byte 6 (4 for random uuids, 0 for nil)

    class version

    source

    A semantic version number (semver.org, version 2.0.0):

    MAJOR.MINOR.PATCH[-PRE-RELEASE][+BUILD]      e.g.  1.4.2,  2.0.0-rc.1,  1.0.0-beta+exp.sha.5114f85
    v := version.parse("1.4.2-beta.3+build7");
v.major                 // 1
v.pre_release           // "beta.3"
(version.parse("1.9.0") < version.parse("1.10.0")).value        // true: numbers, not text
version.parse("1.2.3").next_minor().to_string()                 // "1.3.0"

    ORDER (precedence), as the specification defines it: 1. major, minor and patch are compared as NUMBERS, in that order. 2. A version with a pre-release part comes BEFORE the same version without one: 1.0.0-rc.1 < 1.0.0. 3. Two pre-release parts are compared identifier by identifier (the pieces between the dots): two numbers compare as numbers, a number comes before a word, two words compare by character code; when all shared identifiers are equal the shorter list comes first: alpha < alpha.1 < alpha.beta < beta < beta.2 < beta.11 < rc.1 4. The build part is IGNORED when comparing: 1.0.0+a equals 1.0.0+b.

    Versions are VALUES: the fields are read only and next_major() etc. return new versions.
