    class class_info

    source

    A CLASS, AN INTERFACE OR AN ENUM of the program (see reflect.sharp)

    shape := reflect.of<user>();
shape.name                      // "user"
shape.full_name                 // "app.models#user"
shape.module                    // "app.models"
shape.base_class()              // the class it is based on, or null
shape.is_a(other)               // the same class, one below it, or one that implements it
    shape.fields()                  // its fields and those of the classes above it
shape.field("age")              // one of them (a static one too), or null
shape.functions()               // its functions, and those above it that it did not replace
shape.function("greet")         // the first function with the name, or null
shape.constructors()
    shape.create()                  // an object, by the constructor without parameters
shape.create("ann", new int(31))  // ... by the constructor that takes these
shape.create_array(10)          // user[10], every item null
    colors := reflect.of<color>();  // an enum
colors.values()                 // enum_value: .name, .number, .value
colors.value("red")

    PROTECTIONS. What is private or protected in the class is listed, and is not read, written or called. A class_info from open() allows it:

    shape.field("secret")!!.read(someone)           // reflect_exception
shape.open().field("secret")!!.read(someone)    // allowed
shape.open().create()                           // a private constructor too

    open() gives another class_info for the same class (compare the two by id); the one every other part of the program gets stays closed.

    full_namestringwith the modules: "app.models#user", "std#list<std#string>"

    is_genericdecimal1 for a class made of a generic one: list<string>

    class field_info

    source

    A FIELD of a class (see reflect.sharp)

    age := shape.field("age")!!;
age.name                    // "age"
age.type.name               // "_int64"
age.is_static               age.is_private              age.is_constant
    age.read(someone)           // the value as an object: a number in its number class
age.number(someone)         // the number of a number field
name.text(someone)          // the text of a string field
age.write(someone, 32);     // a number for a number field
name.write(someone, "ann"); // an object for a field of a class

    write checks the value against the field's type and refuses a wrong one with a reflect_exception that names the field. A static field takes null for the object: count.read(null), count.write(null, 0).

    PROTECTIONS. A private or protected field is neither read nor written until it is opened, and a const field is never written:

    secret := shape.field("secret")!!;
secret.read(someone)            // reflect_exception: `main#user.secret` is private ...
secret.open().read(someone)     // said on purpose: allowed

    open() gives another field_info and leaves this one closed, so opening a field in one place does not open it for the rest of the program. shape.open() opens a whole class (class_info).

    class function_info

    source

    A FUNCTION, A CONSTRUCTOR OR AN OPERATOR of a class (see reflect.sharp)

    greet := shape.function("greet")!!;
greet.name                          // "greet"
greet.parameters                    // a type_info for each parameter
greet.result                        // the type_info of what it gives
greet.is_static
    greet.call(someone, "bob")          // someone.greet("bob"): what it gives, as an object
count.call_static()                 // a static function

    What a call gives is an object: a number comes in its number class ((found as int).value), nothing comes as null. An argument for a number parameter is an object of a number class: new int(31).

    A call runs the function that this function_info is - the one written in its class. To run what an object's own class has for a name, ask that class: reflect.of(thing)!!.function("area"), or reflect.on(thing).call("area").

    A private or protected function is not called until it is opened: shape.function("check")!!.open().call(someone), or shape.open() for the whole class. open() gives another function_info; this one stays closed.

    The names of parameters are not kept in a program; their types are.

    class object_view

    source

    ONE OBJECT, BY NAMES: an object together with its class (see reflect.sharp)

    view := reflect.on(someone);
view.read("name")                   // the field's value, as an object
view.number("age")                  // ... as a number
view.text("home.city")              // through objects: null when one on the way is null
view.write("age", 33);
view.write("name", "ann");
view.call("greet", "bob")           // what the object's own class has for the name
view.fields { print(it.name + " = " + it.text() + "\n"); }
    view.to_text()                      // user(name=ann, age=33, home=address(city=oslo))
view.copy()                         // a new object with the same field values
view.same_as(other)                 // the same class and equal field values

    to_text, copy and same_as are what is otherwise written by hand for each class. copy gives the new object the same numbers and the SAME objects in its fields (it does not copy those in turn).

    PROTECTIONS. A view reads, writes, calls and shows what is public. reflect.on(someone).open() is a view that does so for private and protected fields and functions too. copy and same_as go by every field either way: they hand no private value out.

    class reflect

    source

    REFLECTION: a program looking at its own classes

    shape := reflect.of<user>();                    // from a type
shape := reflect.of(someone)!!;                 // from an object
shape := reflect.find("app.models#user")!!;     // from a full name
    foreach(field in shape.fields()) {
    print(field.name + " : " + field.type.name + "\n");     // "tags : list<string>"
}
    someone := reflect.create<user>("ann", new int(31));        // any constructor
age := shape.field("age")!!;
age.number(someone)                             // 31
age.write(someone, 32);                         // checked: a wrong value is refused here
shape.function("greet")!!.call(someone, "bob")  // what greet("bob") gives
    view := reflect.on(someone);                    // one object, by names
view.read("home.city")
view.write("age", 33);
view.to_text()                                  // user(name=ann, age=33, home=address(city=oslo))

    The classes: class_info (a class, an interface or an enum), field_info, function_info, type_info (what a field, a parameter or a result is), object_view (one object with its class), enum_value. Each is made the first time it is asked for and kept; nothing is made when a program starts.

    WHAT IS IN THE PROGRAM. An executable holds only what its text uses: a field no code names and a function no code calls are left out. Reflection shows what is there, so code that works by NAMES says what it needs:

    reflect.of<t>(), reflect.create<t>()    all of t stays: fields, functions, constructors
reflects<t>()                           the fields of t and its constructor without
                                        parameters stay, and the same for the class of
                                        each field (what json.to<t> says)
the compiler option -eager              everything stays (for reflect.find of any class)

    reflect.of(object) and reflect.find(name) always work, and show what stayed.

    Numbers. A value that is read or handed over as an object is an object: a number travels as an int, long, double ... object (new int(31)), and read() gives one back. number() and write(target, 31) take and give plain numbers.

    class reflect_vm

    source

    WHAT THE VM ANSWERS (the library's own; programs use reflect)

    The VM knows no class of std.reflect. It answers questions about the program in plain numbers and characters, and class_info, field_info and function_info are built from the answers. A class is named by its number, a function by its number, a field by its class's number and its place in the class's list of fields (instance fields first, then static ones). What each answer holds: runtime/interrupts/reflection.cpp.

    Functions

    static def call(function_id: _int64, arguments: object[]?) : object?

    Call a function. arguments has one item per parameter and, before them, the object the function is called on when it is a function of an object. What it gives comes back as an object (a number in its number class); null when it gives nothing.

    static def class_of(target: object?) : _int64[]

    what an object is: [ kind, class or -1, array or not, size ]; kind -1 for null

    static def facts(kind: _int64, a: _int64, b: _int64) : _int64[]

    numbers about the program (kind 0), a class (1), a field (2), a class's functions (3), a function (4)

    static def find(full_name: string) : _int64

    the number of the class with a full name, or -1

    static def make(class_id: _int64, count: _int64) : object?

    an object of a class with empty fields and no constructor run (count < 0), or an array with room for count of them

    static def read(class_id: _int64, place: _int64, target: object?) : object?

    a field's value; a number as an object of its number class

    static def text(kind: _int64, a: _int64, b: _int64) : string

    a name: a class's (kind 0), its full name (1), a field's (2), a function's (3), its full name (4)
