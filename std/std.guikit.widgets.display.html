    class chip

    base widget : behavior · source

    chip - a small rounded label: a tag ("work"), a filter you switch on and off, a choice among a few. Made with chip(...).

    chip("work");                                   // just a tag
chip("urgent").selected(only_urgent.value);     // drawn filled while the value is not 0
chip("urgent") { only_urgent.value = 1 - only_urgent.value; }.selected(only_urgent.value);

    A chip does not keep "am I on" itself: like every widget here it shows what a state says, and the click changes the state. (Compose: AssistChip, FilterChip. Android: Chip.)

    class label

    base widget : behavior · source

    label - text on the screen. Made with text(...).

    text("Hello")
text("Total: " + total.value).size(24).color(theme_green)
text(long_paragraph, modifier().max_width(400))     // wraps onto several lines

    .size(px) the font size in pixels (default: the theme's text size) .color(c) the text colour (default: the theme's text colour) .dim() the theme's quieter text colour (captions, hints) .bold() bold .max_lines(n) at most n lines; text cut off ends in "..." .align(how) where the lines sit when the label is wider than its text: ALIGN_START (left), ALIGN_CENTER, ALIGN_END

    Text breaks at a line feed ("\n") always, and between words when it would not fit the width on offer - so a label inside a narrow column wraps by itself. (Compose: Text. Android: TextView. HTML: a span or p.)

    HOW WRAPPING WORKS: measure() is told the room there is. Each paragraph (the text between line feeds) that is wider than the room is cut greedily: words are added to the line while they fit, then a new line starts. The lines are kept for paint(). Measuring text is not free, so the result is remembered for the width it was made for.

    class picture

    base widget : behavior · source

    picture - an image file on the screen. Made with image(...).

    image("assets/logo.png")                              // at its own size
image("assets/photo.jpg", modifier().size(120, 80))   // stretched to a size
image("assets/bg.png", modifier().fill())             // as big as the room there is
image("assets/icon.png").opacity(120)                 // see-through

    The file is loaded the first time the picture is measured and shared from then on (the native side keeps one copy per file), so the same path in a hundred list rows costs one load. PNG transparency is kept. (Compose: Image. Android: ImageView. HTML: img.)

    class progress_bar

    base widget : behavior · source

    progress_bar - how far along something is. Made with gui.progress(...).

    gui.progress(done.value / total)            // a fraction: 0 = nothing, 1 = finished

    It only SHOWS a number (nobody drags it), so it takes a plain value, not a state: build() runs again when your state changes and makes a bar with the new fraction. It is as wide as the room on offer. (Compose: LinearProgressIndicator. HTML: progress.)

    class rich_label

    base widget : behavior · source

    rich_label - shows a rich_text. Made with text(rich { ... }).

    HOW IT WORKS: every part is cut into WORDS (each with the spaces after it). While measuring, the words are laid out left to right and wrapped to the width; each word remembers its line and how far across it is. Painting then only draws each word where it was put.

    class rich_text

    source

    RICH TEXT - one piece of text with parts that look different: a bold word, a coloured number, a quiet aside.

    text(rich {
    plain("Due ");
    bold("tomorrow");
    plain(" at ");
    colored("9:30", gui.current_theme().primary);
    quiet("  (in 14 hours)");
});

    rich { } runs the block and gathers what plain / bold / colored / quiet said into one rich_text; text(...) shows it. The parts flow like one text: the line breaks between words wherever the width runs out, whichever part the word belongs to.

    plain, bold, colored and quiet only mean something inside rich { } - anywhere else they stop the program with a message that says so. (Compose: buildAnnotatedString with SpanStyle. Android: SpannableString.)
