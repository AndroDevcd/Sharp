    class txt

    source

    txt - small text helpers for the widgets that cut text up (label, text_field): txt.slice(words, from, to).

    Functions

    static def after(words: string, at: _int64) : _int64

    the position one letter after at

    static def before(words: string, at: _int64) : _int64

    the position one letter before at

    static def continues_letter(byte: _int64) : _int64

    Text is kept as UTF-8: a letter outside plain English takes two to four bytes. Positions in a text are bytes, so stepping "one letter" means skipping the bytes that only continue a letter (128..191).

    static def in_word(byte: _int64) : _int64

    is this byte part of a word: a letter, a digit, an underscore, or any letter beyond plain English?

    static def is_blank(words: string) : _int64

    is there anything in words besides spaces, tabs and line ends?

    static def letters(words: string, upto: _int64) : _int64

    how many letters (not bytes) the first upto bytes of words hold

    static def slice(words: string, from: _int64, to: _int64) : string

    The part of words from byte from up to (not including) byte to - and simply "" when that part is empty.

    string.substring refuses a start at the very end of the text, even for an empty piece ("everything after the cursor" when the cursor is at the end). Text editing asks for exactly such pieces all the time, so this wraps it.
