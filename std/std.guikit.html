    gui - the front door to the whole framework.

    class counter base composable {
    count := state(0);
        override def build() : element {
        return column(modifier().fill().padding(24)) {
            text("count: " + count.value).size(28);
            button("Add one") { count.value += 1; };
        }.center().gap(12);
    }
}
    def main() {
    gui.run("Counter", 360, 240, new counter());
}

    Every widget function exists twice with the same meaning: here as gui.column(...), gui.text(...), and as a bare word, column(...), text(...) (words.sharp). Use the bare words; reach for gui. when one of them is also a name in your own program.

    THE SHAPE OF EVERY WIDGET FUNCTION

    name(what it needs)                         text("Hello")
name(what it needs, modifier)               text("Hello", modifier().padding(8))
... and a block last, where it takes one    column(modifier().fill()) { ... }
                                            button("Save") { save(); }

    The modifier is the one place a widget's BOX is changed - size, padding, fill, background, click. What a widget IS, it says itself afterwards: text(...).size(24), column { ... }.gap(8), button(...) { }.outline().

    HOW THE FRAMEWORK IS BUILT (start reading at core/tree/behavior.sharp)

    It lives in the standard library, in std/guikit. Every folder is a module of its own, named after its path - a file in std/guikit/core/tree is mod std.guikit.core.tree; - and a program takes the whole family in with

    static def app_icon(path: string)

    The app's icon: the picture in the title bar, the taskbar and the list of open windows. Before gui.run or while the app runs.

    gui.app_icon("art/icon.svg");
gui.run("Sharpcraft", 1280, 720, game);

    The file is one of:

    .ico        Windows' icon file with several sizes in it: the largest is used
.svg        a drawing, painted 256 pixels a side: sharp at every size
a picture   PNG, JPG, BMP, GIF, TGA or PSD; square, and 256 pixels a
            side for an icon that stays sharp where it is shown large

    A file that cannot be read leaves the icon as it was: an app does not stop for want of its icon.

    static def frame_rate(frames: _int64)

    The most frames the app paints in a second. 60 unless the program says otherwise; before gui.run or while the app runs.

    gui.frame_rate(30);     // half the work while something moves: a Raspberry Pi, a laptop on battery
gui.frame_rate(10);     // visibly jerky, and very little work
gui.frame_rate(0);      // no limit: as fast as the machine paints

    It limits PAINTING. An app that stands still paints nothing whatever the rate is; events are read at once and only what they change on the screen waits for the next frame. Animations move by the clock, so a lower rate makes them jerkier, not slower. The lowest rate is 1 (anything below, except 0, counts as 1).

    static def frame_rate() : _int64

    the frame rate in force (0: no limit)

    static def keep_mouse(on: bool)

    true: the window keeps the mouse. The pointer is hidden and cannot leave the window, and a frame's moved_x and moved_y go on saying how far the mouse moved, with no edge of the screen to stop at - what a game needs that looks round with the mouse. false: the pointer is back.

    gui.keep_mouse(true);
on_frame { f: frame -> heading = heading + f.moved_x * 0.2; }

    Only while the app runs (before gui.run there is no window to keep it). The mouse is let go by itself when another window comes to the front (Alt+Tab, the Windows key): ask gui.mouse_kept() and show a pause screen. ALWAYS give the person a key that lets the mouse go - Escape, by custom.

    class sound

    source

    sound - sound the program makes itself: no sound files. A few VOICES, set up once, go on by themselves and together make a place sound alive.

    sound.rumble(140).volume(0.35);                         // the deep sea, always there
sound.hum(55).volume(0.12);                             // a low note under it
sound.chime(520).every(5, 14).volume(0.15);             // a bell-like note, now and then
sound.call(190, 110, 3.5).every(16, 40).volume(0.2);    // a whale, far off
sound.pops(900).every(0.4, 2.5).volume(0.08);           // bubbles
    sound.mute(true);       // silence (the voices go on, unheard);  sound.clear() takes them all away

    THE VOICES

    hum(pitch)              a steady note with a slow swell
rumble(depth)           deep noise that swells and fades: the sea, wind, an engine far off.
                        `depth` is how high it reaches: 80 is a tremor, 300 is surf
chime(pitch)            a note that rings out like a bell, each time one of five notes
                        that sound well together in any order
call(from, to, seconds) a note that glides from one pitch to another: a whale, a siren
pops(pitch)             short rising blips: bubbles, drips

    A pitch is in turns of the wave a second (Hz): 110 is a low A, 440 the A an orchestra tunes to.

    Set them up ONCE - when the app starts, not in build(), which runs again and again. A machine without sound stays silent; nothing fails. (Web Audio: OscillatorNode, BiquadFilterNode and GainNode wired by hand.)

    def underwater(shallow: _int64, deep: _int64) : water

    The eye is IN water: everything fades into the water's colour with distance, the surface ripples overhead, and the sun through it throws moving light on what is below. shallow is the water's colour near the surface, deep its colour below. What comes back sets the rest:

    underwater(0x35C6D0FF, 0x0A2E4AFF).surface(40).sight(70).caustics(0.8).light_shafts(0.6);

    It takes the place of the sky and of fog(...). The sun still decides where the light comes from, and its shadows fall as on land.
