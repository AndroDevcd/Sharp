    class hit_box

    source

    hit_box - a rectangle that things in a game are checked against: does the player touch the coin, is the click inside the button, did the bullet hit.

    player := new hit_box(x, y, 32, 48);
coin := new hit_box(400, 200, 16, 16);
    if(player.overlaps(coin)) { ... }
if(player.contains(f.mouse_x, f.mouse_y)) { ... }

    Its fields are plain numbers: move a hit box by changing x and y. Hit boxes that only share an edge do not overlap.

    class sprite_animation

    source

    sprite_animation - which frame of a sprite sheet to show, as time passes.

    run := new sprite_animation(8, 6, 12);       // frames 8 .. 13, twelve a second
    p.sprite(hero, run.frame_at(f.time), x, y);  // in the canvas, every frame

    It holds no clock of its own: hand frame_at the seconds since the animation began - f.time for one that just loops, or f.time - jumped_at for one that starts at a moment. So one animation serves every character that uses it, each at its own point, and the speed is the same at any frame rate.

    It loops for ever unless once() is called: then it stops on its last frame, and finished(seconds) says when (a jump, an explosion).

    class sprite_batch

    source

    sprite_batch - many sprites of ONE sheet, painted with one call.

    coins := new sprite_batch(items);            // once: items is a sprite_sheet
    coins.clear();                               // every frame
for(...) { coins.add(spin.frame_at(f.time), x, y); }
p.draw(coins);

    The same idea as shape_batch: p.sprite(...) crosses into the graphics side for every sprite, a batch crosses once for all of them. Use it wherever many sprites come from the same sheet - a crowd, bullets, coins, particles. They are painted in the order they were added.

    class sprite_sheet

    source

    sprite_sheet - one picture that holds many small ones of the same size, in rows: the frames of a character's run, the tiles of a level.

    hero := new sprite_sheet("assets/hero.png", 32, 32);     // frames of 32 x 32 pixels
p.sprite(hero, 5, x, y);                                 // frame 5, at its own size
p.sprite(hero, 5, x, y, 96, 96);                         // three times as large
p.sprite(hero, 5, x, y, 96, 96, true);                   // facing the other way

    FRAMES ARE NUMBERED from 0, left to right and then down - the top-left frame is 0, the one to its right is 1, and the first of the second row comes after the last of the first.

    PIXEL ART: call crisp() once. A picture is normally smoothed when it is drawn larger than it is, which is right for a photo and turns pixel art to mush; crisp() keeps every pixel a sharp square.

    Some sheets leave a gap around the frames: margin is the gap between the picture's edge and the first frame, spacing the gap between two frames.

    Make a sheet once, before the frame loop (it needs an open window, like every picture). Animations are sprite_animation; many sprites at once sprite_batch; a level made of tiles tile_map.

    class tile_map

    source

    tile_map - a level laid out as a grid of tiles from a tile set.

    ground := new sprite_sheet("assets/tiles.png", 18, 18).crisp();
level := new tile_map(ground, 200, 20);          // 200 tiles wide, 20 high
level.tile_size(36, 36);                         // painted twice the tile's own size
level.fill(0, 18, 200, 2, 3);                    // two rows of tile 3 along the bottom
level.put(12, 17, 48);                           // one tile
level.solid(3);                                  // tile 3 is something to stand on
    p.tiles(level, camera_x, camera_y, f.width, f.height);     // in the canvas

    TILE NUMBERS: 0 is "nothing here". Tile n is frame n - 1 of the sheet, so tile 1 is the sheet's top-left frame. (A new map is all 0: empty. The Tiled map editor numbers tiles the same way.)

    THE CAMERA is the point of the map that is at the view's top-left corner, in the map's painted pixels: moving it scrolls the level. p.tiles paints only the tiles inside the view, in one call - a map of a million tiles costs the same to paint as a small one.

    WALLS AND FLOORS: mark tiles solid(...), and blocked(x, y, w, h) says whether a box - a character - would be inside one. Move, ask, and move back if so.
