    std.guikit.widgets.drawing module

    canvas frame

    class canvas

    base widget : behavior · source

    canvas - an area you paint yourself, every frame. Made with canvas(...).

    This is the escape hatch out of the widgets: a chart, a drawing surface, a whole game. You get the painter and draw whatever you like; the rest of the screen around it is still ordinary widgets.

    ball_x : decimal = 50;
    canvas(modifier().fill()) { p: painter, f: frame ->
    if(f.key_down(KEY_RIGHT) == 1) { ball_x = ball_x + 200 * f.step; }
    p.rect(0, 0, f.width, f.height, sky);
    p.circle(ball_x, f.height / 2, 20, red);
}

    INSIDE THE FUNCTION, (0, 0) is the canvas's own top-left corner and nothing you draw can spill outside the canvas - so the same drawing code works wherever the canvas sits in the layout and whatever size it is given.

    A canvas is painted again EVERY frame (about 60 times a second), which is what animation and games need. For a picture that only changes when your state does (a chart), call .still(): it is then painted only when the screen is, and an idle app goes back to sleep.

    (Compose: Canvas. Android: a custom View's onDraw. HTML: the canvas element with requestAnimationFrame.)
