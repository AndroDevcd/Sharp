    std.guikit.layout.stacking module

    stack

    class stack

    base widget : behavior · source

    stack - children on top of each other, like sheets of paper. The first child is at the bottom, the last on top.

    stack {
    image("photo.png", modifier().fill());               // the background
    text("Caption", modifier().padding(8));              // over it, top-left
}
    stack(modifier().fill()) {                               // children sit bottom-right ...
    content_of_the_page();                               // ... except ones that fill
    button("+") { add(); };                              // a floating button
}.place(ALIGN_END, ALIGN_END)

    The stack is as big as its biggest child (or whatever its modifier says). A child that fills covers the whole stack; any other child keeps its own size and sits where place(across, down) says - top-left by default. (Compose: Box. Android: FrameLayout. CSS: position: absolute children.)
