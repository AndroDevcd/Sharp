    class big_integer

    source

    A whole number of any size (arbitrary precision), for results that do not fit in the 53 exact bits of a native number: 30!, 2^200, long products.

    a := new big_integer("123456789012345678901234567890");
b := big_integer.of(987654321);
c := a * b + 1;
println(c.to_string());
f := big_integer.factorial(30);     // 265252859812191058636308480000000

    Big integers are VALUES: no method changes the object it is called on, every operation returns a new big_integer.

    Operators: + - * / % with a big_integer or a whole native number on the right, unary -, == != < > <= >=. Division rounds toward zero and the remainder has the sign of the dividend, the same as for whole native numbers (and as Java's BigInteger): -7 / 2 == -3, -7 % 2 == -1.

    REPRESENTATION A sign flag plus the magnitude in an array of "limbs". Each limb holds 7 decimal digits (base 10 000 000), the least significant limb first:

    123456789012  ->  limbs { 6789012, 12345 }

    Base 10^7 is used because the product of two limbs (< 10^14) plus carries stays far below 2^53, so all limb arithmetic is exact in native numbers, and because converting to and from decimal text needs no division. The array never has leading zero limbs (zero is the single limb { 0 }) and zero is never negative, so equal numbers always have equal fields.

    class bits

    source

    Bit tricks on whole numbers. Only static functions; never instantiated.

    bits.count_ones(255)            // 8
bits.highest_one_bit(100)       // 64
bits.is_power_of_two(64)  // true
bits.next_power_of_two(100)     // 128
bits.rotate_left(1, 31)         // 2147483648

    RANGE. A native number holds whole values exactly up to 2^53, so the counting and searching functions accept any whole number in 0 .. 2^53. The functions with a fixed word size (rotate_left, rotate_right, reverse, invert, leading_zeros) treat their argument as an UNSIGNED 32-bit word, 0 .. 4294967295, and return such a word.

    Every function throws illegal_argument_exception for a negative number, a fraction, or a value above its range.

    The functions use division and multiplication by powers of two instead of the shift operators, which keeps them exact over the whole range.

    static def clear_bit(n: decimal, position: decimal): decimal

    n with the bit at position set to 0: clear_bit(5, 0) == 4

    static def count_ones(n: decimal): decimal

    how many bits of n are 1 (the "population count"): count_ones(13) == 3 because 13 is 1101

    static def highest_one_bit(n: decimal): decimal

    The value of the highest 1 bit: the largest power of two <= n. highest_one_bit(100) == 64; highest_one_bit(0) == 0.

    static def invert(n: decimal): decimal

    every bit of the 32-bit word n flipped (bitwise NOT): invert(0) == 4294967295

    static def is_power_of_two(n: decimal): bool

    true when n is 1, 2, 4, 8 ... (exactly one bit is set); false for 0

    static def leading_zeros(n: decimal): decimal

    How many 0 bits are above the highest 1 bit of the 32-bit word n: leading_zeros(1) == 31, leading_zeros(0) == 32, leading_zeros(4294967295) == 0.

    static def lowest_one_bit(n: decimal): decimal

    The value of the lowest 1 bit: the largest power of two that divides n. lowest_one_bit(12) == 4 (12 is 1100); lowest_one_bit(0) == 0.

    static def next_power_of_two(n: decimal): decimal

    The smallest power of two that is >= n: next_power_of_two(100) == 128, next_power_of_two(64) == 64, next_power_of_two(0) == 1.

    static def parse_binary(text: string): decimal

    Read a binary number: parse_binary("1010") == 10. Throws number_format_exception when the text is empty, has a character other than 0 and 1, or has more than 53 digits.

    static def reverse(n: decimal): decimal

    The 32-bit word n with its bits in the opposite order (bit 0 becomes bit 31 ...): reverse(1) == 2147483648, reverse(4294967295) == 4294967295.

    static def rotate_left(n: decimal, distance: decimal): decimal

    The 32-bit word n rotated left by distance bits: bits pushed out at the top come back in at the bottom. rotate_left(1, 31) == 2147483648, rotate_left(2147483648, 1) == 1. Any distance is allowed (it is taken modulo 32; a negative distance rotates right).

    Algorithm: split n at bit (32 - distance) into a high and a low part and swap them: low * 2^distance + high.

    static def rotate_right(n: decimal, distance: decimal): decimal

    The 32-bit word n rotated right by distance bits: rotate_right(1, 1) == 2147483648. The same as rotating left by 32 - distance.

    static def set_bit(n: decimal, position: decimal): decimal

    n with the bit at position set to 1: set_bit(4, 0) == 5

    static def test_bit(n: decimal, position: decimal): bool

    true when the bit at position (0 = lowest) of n is 1: test_bit(5, 2) is true because 5 is 101

    static def to_binary_string(n: decimal): string

    n written in binary, without leading zeros: to_binary_string(10) is "1010", to_binary_string(0) is "0".

    static def toggle_bit(n: decimal, position: decimal): decimal

    n with the bit at position flipped: toggle_bit(5, 1) == 7, toggle_bit(7, 1) == 5

    static def trailing_zeros(n: decimal): decimal

    How many 0 bits are below the lowest 1 bit: trailing_zeros(8) == 3, trailing_zeros(1) == 0. For 0 the answer is 32 (all bits of the word are zero), the convention of Java and Kotlin.

    class fraction

    source

    An exact rational number numerator / denominator.

    Unlike a floating point number a fraction has no rounding error: 1/3 + 1/6 is exactly 1/2. A fraction is always kept NORMALISED:

    - numerator and denominator have no common divisor (6/8 is stored as 3/4) - the denominator is positive (1/-2 is stored as -1/2) - zero is 0/1

    so two equal fractions always have equal fields. Fractions are VALUES: the fields cannot be changed from outside and every operation returns a new fraction.

    a := new fraction(1, 3);
b := new fraction(1, 6);
c := a + b;                 // 1/2
d := c * 4;                 // 2
x : decimal = c.to_var();       // 0.5

    Operators: + - * / with a fraction or a whole number on the right, unary -, == != < > <= >=.

    Numerator and denominator are native numbers, so they are exact up to 2^53; results whose parts grow beyond that lose exactness (use big_integer based arithmetic for such sizes).

    class matrix

    source

    A matrix of native numbers with any number of rows and columns.

    The cells are stored row after row in one flat array ("row-major"): the cell in row r and column c is cells[r * columns + c]. Rows and columns are counted from 0.

    m := new matrix(2, 2);          // 2 x 2, all zeros
m.put(0, 0, 4); m.put(0, 1, 7);

    Operators: + - (matrix), * (matrix or number), unary -, == !=. All operators and the methods transpose(), inverse(), pow() ... return NEW matrices; only put() and fill() change the matrix they are called on.

    Wrong sizes throw illegal_argument_exception, positions outside the matrix throw out_of_bounds_exception, and operations that have no answer (the inverse of a singular matrix) throw arithmetic_exception.

    class statistics

    source

    Descriptive statistics over arrays of native numbers. The class only has static functions and is never instantiated:

    data := new decimal[] { 2, 4, 4, 4, 5, 5, 7, 9 };

    n! = 1 * 2 * ... * n, with 0! == 1. Exact up to 18! (6402373705728000); larger results are rounded to 53 bits and 171! and above are infinity. Use big_integer.factorial() when every digit matters.

    Throws illegal_argument_exception when n is negative or not whole.

    def fibonacci(n: decimal): decimal

    The n-th Fibonacci number, counting from fibonacci(0) == 0 and fibonacci(1) == 1: 0, 1, 1, 2, 3, 5, 8, 13 ... Exact up to fibonacci(78) == 8944394323791464.

    Algorithm: a loop that keeps the last two numbers (no recursion). Throws illegal_argument_exception when n is negative or not whole.

    def floor(v: decimal): decimal

    the largest whole number that is <= v: floor(2.9) is 2, floor(-2.5) is -3

    def floor_div(dividend: decimal, divisor: decimal): decimal

    Division that rounds toward negative infinity (Kotlin floorDiv): floor_div(7, 2) == 3, floor_div(-7, 2) == -4, floor_div(7, -2) == -4.

    Throws division_by_zero_exception when divisor is 0.

    def floor_mod(dividend: decimal, divisor: decimal): decimal

    The remainder that goes with floor_div (Kotlin mod / Java floorMod); it has the sign of the DIVISOR, so for a positive divisor it is never negative, which is what indexing and clock arithmetic need: floor_mod(7, 3) == 1, floor_mod(-7, 3) == 2, floor_mod(7, -3) == -2.

    Formula: dividend - floor(dividend / divisor) * divisor. Throws division_by_zero_exception when divisor is 0.

    def floor_to(v: decimal, decimals: decimal): decimal

    round DOWN to decimals digits after the point: floor_to(3.149, 2) == 3.14

    def fmod(a: decimal, b: decimal): decimal

    what is left of a / b, with the sign of a (the % of plain numbers, for fractions too): fmod(7.5, 2) is 1.5

    def fract(v: decimal): decimal

    The fractional part, with the sign of v: fract(2.75) == 0.75, fract(-2.75) == -0.75. Always v == trunc(v) + fract(v).

    def gcd(a: decimal, b: decimal): decimal

    Greatest common divisor: the largest whole number that divides both a and b. Signs are ignored and the result is never negative: gcd(12, 18) == 6, gcd(-12, 18) == 6, gcd(0, 5) == 5, gcd(0, 0) == 0.

    Algorithm: Euclid - replace (a, b) by (b, a mod b) until b is 0.

    def hypot(x: decimal, y: decimal): decimal

    Length of the hypotenuse, sqrt(x^2 + y^2), without overflowing for large arguments: hypot(3, 4) == 5.

    Algorithm: with m the larger and s the smaller of |x| and |y|, m * sqrt(1 + (s / m)^2) - the intermediate values never exceed the result.

    def hypot(x: decimal, y: decimal, z: decimal): decimal

    the 3D version of hypot: sqrt(x^2 + y^2 + z^2); hypot(2, 3, 6) == 7

    def int_div(dividend: decimal, divisor: decimal): decimal

    Whole number division that rounds toward zero, the way integer division works in C, Java and Kotlin: int_div(7, 2) == 3, int_div(-7, 2) == -3.

    Throws division_by_zero_exception when divisor is 0.

    def int_pow(base_value: decimal, exponent: decimal): decimal

    base^exponent for a whole, non-negative exponent, by repeated squaring (O(log exponent) multiplications, no call into the runtime). The result is exact whenever it fits in 53 bits: int_pow(3, 20) == 3486784401. int_pow(x, 0) == 1 for every x, including 0.

    Throws illegal_argument_exception when exponent is negative or not whole.

    def int_rem(dividend: decimal, divisor: decimal): decimal

    The remainder that goes with int_div; it has the sign of the dividend (the same as the % operator on whole numbers): int_rem(7, 3) == 1, int_rem(-7, 3) == -1. Always dividend == int_div(a, b) * b + int_rem(a, b).

    Throws division_by_zero_exception when divisor is 0.

    def inverse_lerp(a: decimal, b: decimal, v: decimal): decimal

    The opposite of lerp: how far v is along the way from a to b, as a fraction. inverse_lerp(10, 20, 12.5) == 0.25.

    Throws arithmetic_exception when a == b (every v is then "nowhere" on a line of length 0).

    def is_even(n: decimal): bool

    true when the whole number n is divisible by 2 (also for negative n)

    def is_finite(v: decimal): bool

    True when v is an ordinary number: not NaN and not +-infinity. (v - v is 0 for every finite number and NaN for the other three.)

    public def is_infinite(v: decimal): bool

    true when v is positive or negative infinity

    public def is_nan(v: decimal): bool

    true when v is NaN ("not a number", what 0 / 0 gives)

    def is_odd(n: decimal): bool

    true when the whole number n is not divisible by 2 (also for negative n)

    def is_perfect_square(n: decimal): bool

    true when n is the square of a whole number: 0, 1, 4, 9, 16 ... (false for negatives and fractions)

    def is_prime(n: decimal): bool

    True when n is a prime number (a whole number > 1 whose only divisors are 1 and itself). 0, 1, negative numbers and fractions are not prime.

    Algorithm: trial division. After 2 and 3 every prime has the form 6k - 1 or 6k + 1, so only those candidates up to sqrt(n) are tried: O(sqrt(n)) steps, fine up to about 10^12.

    def is_whole(v: decimal): bool

    true when v has no fractional part (and is finite): 3, -7, 1e20

    def isqrt(n: decimal): decimal

    Whole number square root: the largest whole r with r * r <= n. isqrt(17) == 4, isqrt(16) == 4, isqrt(0) == 0. Exact for n up to 2^53.

    Algorithm: floor(sqrt(n)), then corrected by at most one step in either direction in case the floating point root was rounded across a whole number.

    Throws illegal_argument_exception when n is negative.

    def lcm(a: decimal, b: decimal): decimal

    Least common multiple: the smallest positive whole number that both a and b divide. lcm(4, 6) == 12; lcm(0, n) == 0.

    Formula: |a| / gcd(a, b) * |b| (dividing first keeps the intermediate value small).

    def ldexp(v: decimal, exponent: decimal): decimal

    v * 2 to the power exponent

    def lerp(a: decimal, b: decimal, t: decimal): decimal

    Linear interpolation: the value a fraction t of the way from a to b. lerp(10, 20, 0) == 10, lerp(10, 20, 1) == 20, lerp(10, 20, 0.25) == 12.5. t outside 0 .. 1 extrapolates along the same line.

    Formula: a + (b - a) * t.

    def log(v: decimal): decimal

    the natural logarithm of v (base e); log(0) is negative infinity, of a negative number NaN

    def log10(v: decimal): decimal

    the logarithm of v to the base 10: log10(1000) is 3

    def log2(v: decimal): decimal

    Base 2 logarithm: log2(8) == 3, log2(1) == 0. log2(0) is negative infinity, log2 of a negative number is NaN.

    Whole powers of two (and their reciprocals) are returned exactly: the result of log(v) / LN2 is rounded and kept when 2^rounded == v.

    def log_base(v: decimal, base_value: decimal): decimal

    Logarithm of v in any base: log_base(81, 3) == 4. Formula: log(v) / log(base).

    Throws illegal_argument_exception when base is <= 0 or is 1 (no such logarithm exists).

    def map_range(v: decimal, in_low: decimal, in_high: decimal, out_low: decimal, out_high: decimal): decimal

    Re-scale v from the range in_low .. in_high to the range out_low .. out_high, keeping its relative position: map_range(5, 0, 10, 100, 200) == 150 (half way stays half way). Values outside the input range land outside the output range; the output range may run backwards (map_range(2, 0, 10, 10, 0) == 8).

    Throws arithmetic_exception when in_low == in_high.

    def math_call(a: decimal, b: decimal, proc: _int64): decimal

    Run math procedure proc of the runtime on a (and b for the procedures that take two; 0 otherwise): for code that only knows WHICH function when it runs. The functions of this module do not come here: each is an instruction of the runtime with its number written in it (dmath; sqrt, ceil, floor and abs have instructions of their own), and with -O a call of one becomes that instruction where it is written.

    0x00 sin    0x01 cos    0x02 tan    0x03 sinh   0x04 cosh   0x05 tanh
0x06 asin   0x07 acos   0x08 atan   0x09 atan2(a, b)        0x0a exp
0x0b log    0x0c log10  0x0d pow(a, b)          0x0e sqrt   0x0f ceil
0x10 floor  0x11 fabs   0x12 ldexp(a, b)        0x13 fmod(a, b)

    Throws invalid_operation_exception (raised by the runtime) when proc is not one of these numbers.

    def max(a: decimal, b: decimal): decimal

    the larger of two numbers; NaN if either one is NaN

    def max(a: decimal, b: decimal, c: decimal): decimal

    the largest of three numbers

    def max_of(values: decimal[]): decimal

    The largest number in an array (any number of values). Throws illegal_argument_exception when the array is empty.

    def min(a: decimal, b: decimal): decimal

    the smaller of two numbers; NaN if either one is NaN

    def min(a: decimal, b: decimal, c: decimal): decimal

    the smallest of three numbers

    def min_of(values: decimal[]): decimal

    The smallest number in an array (any number of values). Throws illegal_argument_exception when the array is empty.

    def mod_pow(base_value: decimal, exponent: decimal, modulus: decimal): decimal

    (base ^ exponent) mod modulus without ever forming the huge power: mod_pow(4, 13, 497) == 445. The result is in 0 .. modulus - 1.

    Algorithm: square-and-multiply, reducing after every multiplication. Every product of two reduced values must stay exact, which limits the modulus to 94906265 (just under 2^26.5, so products stay below 2^53).

    Throws illegal_argument_exception when exponent is negative, or modulus is < 1 or above that limit.

    def next_prime(n: decimal): decimal

    the smallest prime that is greater than n: next_prime(7) == 11, next_prime(-5) == 2

    def normalize_degrees(degrees: decimal): decimal

    Bring an angle in degrees into 0 <= angle < 360: normalize_degrees(-90) == 270, normalize_degrees(725) == 5.

    def normalize_radians(radians: decimal): decimal

    Bring an angle in radians into 0 <= angle < 2 pi by adding or removing whole turns: normalize_radians(-pi/2) == 3pi/2.

    def nth_root(v: decimal, n: decimal): decimal

    The n-th root of v: nth_root(32, 5) == 2. For an odd n a negative v is allowed (nth_root(-27, 3) == -3); for an even n it gives NaN.

    Throws illegal_argument_exception when n is 0.

    def number_to_fixed(v: decimal, decimals: decimal): string

    v with exactly decimals digits after the decimal point, rounded: number_to_fixed(3.14159, 2) is "3.14", number_to_fixed(2, 3) is "2.000", number_to_fixed(2.5, 0) is "3".

    Throws illegal_argument_exception when decimals is negative or above 100.

    def number_to_string(v: decimal): string

    The shortest text that reads back as exactly v - what "" + v gives:

    3        -> "3"            -0.5   -> "-0.5"
2.50     -> "2.5"          0.1    -> "0.1"
1e21     -> "1e+21"        1e-20  -> "1e-20"
NaN      -> "NaN"          1 / 0  -> "Infinity"   -1 / 0 -> "-Infinity"

    The VM makes this text (the fewest digits that give the same number again), so a number printed here, added to a string, or written by json always looks the same.

    def permutations(n: decimal, k: decimal): decimal

    The number of ways to pick k items out of n when the order DOES matter: n * (n - 1) * ... * (n - k + 1). permutations(5, 2) == 20; 0 when k > n.

    Throws illegal_argument_exception when n or k is negative.

    def pow(base_value: decimal, exponent: decimal): decimal

    base_value raised to the power exponent: pow(2, 10) is 1024, pow(2, 0.5) is sqrt(2), pow(x, 0) is 1. A negative base with a fractional exponent gives NaN.

    def prime_factors(n: decimal): decimal[]

    The prime factors of n in rising order, repeated as often as they divide n: prime_factors(360) is { 2, 2, 2, 3, 3, 5 }. A prime gives an array holding just itself; 1 gives an empty array.

    Throws illegal_argument_exception when n is < 1 or not whole.

    def round(v: decimal): decimal

    Round to the nearest whole number; a tie (x.5) goes away from zero: round(2.5) is 3, round(2.4) is 2, round(-2.5) is -3 (round_half_away of rounding.sharp; round_half_even is the other rule).

    def round_half_away(v: decimal): decimal

    Round to the nearest whole number; a tie (x.5) goes AWAY from zero, which is what people usually call rounding: 2.5 -> 3, -2.5 -> -3, 2.4 -> 2.

    def round_half_even(v: decimal): decimal

    Round to the nearest whole number; a tie (x.5) goes to the EVEN neighbour ("banker's rounding", the rule Kotlin's round() uses): 2.5 -> 2, 3.5 -> 4, -2.5 -> -2. Over many values this does not drift upward the way round_half_away does.

    def round_to(v: decimal, decimals: decimal): decimal

    Round to decimals digits after the decimal point (ties away from zero): round_to(3.14159, 2) == 3.14, round_to(2.5, 0) == 3. A negative count rounds to the left of the point: round_to(1234, -2) == 1200.

    Formula: round_half_away(v * 10^decimals) / 10^decimals. The usual floating point caveat applies: 1.005 is stored as 1.00499999999999989..., so round_to(1.005, 2) is 1 and not 1.01.

    def round_to_multiple(v: decimal, step: decimal): decimal

    Round v to the nearest multiple of step (ties away from zero): round_to_multiple(17, 5) == 15, round_to_multiple(18, 5) == 20.

    Throws division_by_zero_exception when step is 0.

    def sec(radians: decimal): decimal

    secant: 1 / cos. Infinite where the cosine is 0.

    def sign(v: decimal): decimal

    The sign of a number: -1 for negative, 1 for positive, 0 for zero. NaN is returned unchanged (it is neither negative nor positive).

    def sin(radians: decimal): decimal

    sine of an angle in radians

    def sinh(v: decimal): decimal

    hyperbolic sine as a native number: (e^v - e^-v) / 2

    def smoothstep(edge0: decimal, edge1: decimal, x: decimal): decimal

    A smooth 0 -> 1 transition as x goes from edge0 to edge1: 0 at or below edge0, 1 at or above edge1, and an S shaped curve with zero slope at both ends in between (smoothstep(0, 10, 5) == 0.5).

    Formula: t = clamp((x - edge0) / (edge1 - edge0), 0, 1); t * t * (3 - 2 t). Throws arithmetic_exception when edge0 == edge1.

    def sqrt(v: decimal): decimal

    The square root; NaN for a negative number. It is one instruction of the runtime (dsqrt: the processor's own square root), and with -O a call of this function becomes that instruction where it is written.

    def square(v: decimal): decimal

    v * v

    def tan(radians: decimal): decimal

    tangent of an angle in radians

    def tanh(v: decimal): decimal

    def trunc(v: decimal): decimal

    Drop the fractional part (round toward zero): trunc(2.9) == 2, trunc(-2.9) == -2. NaN and the infinities are returned unchanged.

    def wrap(v: decimal, low: decimal, high: decimal): decimal

    Throws illegal_argument_exception when low >= high.
