    class ascii

    source

    ascii

    Names for the ASCII characters that cannot be typed as a character literal, and a few helpers for working with character codes. Everything is static.

    sb.append_char(ascii.escape).append("[1m");      // start bold on a terminal
if(c == ascii.form_feed) ...
ascii.name_of(10)        "LF"
ascii.caret(3)           "^C"

    The constants are native numbers and can be used wherever a character is expected (append_char, comparisons with char_at, char parameters). For questions such as "is this a digit" see std.text#character.

    Fields

    nuldecimalcode 0: the NUL character
    belldecimalcode 7: bell (makes a terminal beep)
    backspacedecimalcode 8: backspace
    tabdecimalcode 9: horizontal tab, '\t'
    line_feeddecimalcode 10: line feed, '\n' - the line end on Linux and macOS
    vertical_tabdecimalcode 11: vertical tab
    form_feeddecimalcode 12: form feed (page break)
    carriage_returndecimalcode 13: carriage return, '\r' - Windows line ends are carriage return + line feed
    escapedecimalcode 27: escape, the start of terminal control sequences
    spacedecimalcode 32: the space
    double_quotedecimalcode 34: the double quote "
    dollardecimalcode 36: the dollar sign, which cannot be written inside a Sharp string literal
    single_quotedecimalcode 39: the single quote '
    backslashdecimalcode 92: the backslash
    delete_chardecimalcode 127: delete
    max_codedecimalthe largest ASCII code, 127

    Functions

    static def caret(c: char): string

    Caret notation, as terminals show control characters: "^@" for 0, "^A" for 1 ... "^Z" for 26, "^[" for escape, "^?" for delete. A character that is not a control character is returned as it is.

    static def is_ascii(code: char): bool

    true if code is an ASCII code, 0 to 127.

    static def is_ascii_text(text: string): bool

    true if every character of text is ASCII ("" gives 1).

    static def name_of(c: char): string

    A readable name for the character: the standard abbreviation for control characters ("NUL", "HT", "LF", "CR", "ESC" ...), "SPACE" for the space, "DEL" for 127, the character itself for visible characters ("A", "~"), and "0x" plus two hexadecimal digits for bytes outside of ASCII ("0xe9"). Useful in error messages and hex dumps.

    static def printable(text: string, replacement: char): string

    text with every character that is not visible ASCII replaced by replacement: control characters, delete and bytes above 127. Spaces are kept. printable("a\tb", '.') is "a.b".

    static def unsigned_code(c: char): decimal

    The code of the character as an unsigned number, 0 to 255. Characters are stored as signed bytes, so a byte above 127 reads as a negative number; this gives the value a hex dump would show.

    class case_format

    source

    case_format

    Converts names between the usual spellings. All functions are static:

    case_format.to_snake("parseHttpRequest")        "parse_http_request"
case_format.to_camel("parse_http_request")      "parseHttpRequest"
case_format.to_pascal("parse-http-request")     "ParseHttpRequest"
case_format.to_kebab("ParseHTTPRequest")        "parse-http-request"
case_format.to_screaming_snake("max size")      "MAX_SIZE"
case_format.to_title("max_size")                "Max Size"

    Every conversion first cuts the input into words (see split_words) and then writes the words in the wanted style, so any style can be converted into any other, and mixed input ("some_mixedInput-here") works too.

    How a name is cut into words - at '_', '-', '.', spaces and other whitespace (these are dropped; several in a row count as one) - before a capital letter that follows a small letter or a digit: "max_size" -> max | Size, "v2Final" -> v2 | Final - before the last capital of a run of capitals when a small letter follows, so abbreviations stay together: "HTTPServer" -> HTTP | Server - digits stay with the word in front of them: "utf8Text" -> utf8 | Text

    Only ASCII letters are handled. An empty or separator-only input gives "".

    Functions

    static def split_words(name: string): string[]

    The words of name, all in small letters, in order: split_words("parseHTTPRequest_v2") is ["parse", "http", "request", "v2"]. An empty or separator-only name gives an array of length 0.

    static def to_camel(name: string): string

    camelCase: first word small, the others capitalised, nothing between. to_camel("max_size") is "max_size".

    static def to_dot(name: string): string

    dot.case: small letters, words joined with '.'. to_dot("max_size") is "max.size".

    static def to_kebab(name: string): string

    kebab-case: small letters, words joined with '-'. to_kebab("max_size") is "max-size".

    static def to_pascal(name: string): string

    PascalCase: every word capitalised, nothing between. to_pascal("max_size") is "MaxSize".

    static def to_screaming_snake(name: string): string

    SCREAMING_SNAKE_CASE, as used for constants: to_screaming_snake("max_size") is "MAX_SIZE".

    static def to_sentence(name: string): string

    Sentence case: first word capitalised, the rest small, spaces between. to_sentence("maxSizeLimit") is "Max size limit".

    static def to_snake(name: string): string

    snake_case: small letters, words joined with '_'. to_snake("max_size") is "max_size".

    static def to_title(name: string): string

    Title Case for people: every word capitalised, spaces between. to_title("max_size") is "Max Size".

    static def word_count(name: string): decimal

    How many words the name has: word_count("parseHTTPRequest") is 3.

    char_sets

    Ready-made sets of characters, as strings, for the many functions that take "any of these characters": string.trim_chars, split_any, index_of_any, remove_chars, retain_chars, string_reader.read_while_in, string_tokenizer ...

    digits_only := phone.retain_chars(char_sets.digits());
word := reader.read_while_in(char_sets.letters());
if(password.contains_any(char_sets.punctuation())) ...

    and helpers to build and combine sets: range, union, difference, intersection, and tests such as all_in / none_in.

    A set is simply a string; the order of the characters does not matter to the functions that use it, and a character listed twice counts once. Everything is static. All sets are ASCII.

    class number_format

    source

    number_format

    Turns numbers into text. All functions are static and take the number as a native decimal:

    number_format.integer(42)                 "42"
number_format.fixed(3.14159, 2)           "3.14"
number_format.trimmed(2.50, 4)            "2.5"
number_format.grouped(1234567.891, 2)     "1,234,567.89"
number_format.padded(7, 3)                "007"
number_format.hex(255)                    "ff"
number_format.binary(5, 8)                "00000101"
number_format.scientific(31415.9, 2)      "3.14e+04"
number_format.percent(0.256, 1)           "25.6%"
number_format.ordinal(22)                 "22nd"
number_format.bytes(1536)                 "1.5 KB"
number_format.roman(1994)                 "MCMXCIV"

    Things to know - Rounding is "half away from zero" on the value the number really has: fixed(2.5, 0) is "3", fixed(-2.5, 0) is "-3". Because numbers are binary floating point, a value written as 1.005 is really 1.00499999999999989... and fixed(1.005, 2) is therefore "1.00". - A result that rounds to zero never has a minus sign: fixed(-0.001, 2) is "0.00". - Whole numbers are exact up to 9007199254740991 (2^53 - 1). Larger numbers are still printed, with the digits the floating point value has. - Not-a-number prints as "NaN", the infinities as "Infinity" / "-Infinity". - Unlike "" + number (which prints 16 decimals) and int.to_string() (which is limited to 32 bit), these work on any native number.

    Functions

    static def binary(number: decimal): string

    The whole number in binary: binary(5) is "101".

    static def binary(number: decimal, width: int): string

    binary(number) with at least width digits: binary(5, 8) is "00000101".

    static def bytes(number: decimal): string

    A size in bytes in the largest fitting unit (1 KB = 1024 B): bytes(512) is "512 B", bytes(1536) is "1.5 KB", bytes(1048576) is "1.0 MB". Units go up to EB; from KB on there is one decimal. Throws illegal_argument_exception if the number is negative.

    static def fixed(number: decimal, decimals: int): string

    The number with exactly decimals digits after the point, rounded: fixed(3.14159, 2) is "3.14", fixed(2, 2) is "2.00", fixed(2.5, 0) is "3". Throws illegal_argument_exception if decimals is not between 0 and 15.

    static def grouped(number: decimal): string

    The number rounded to a whole number, with commas between groups of three digits: grouped(1234567) is "1,234,567", grouped(-1234.5) is "-1,235".

    static def grouped(number: decimal, decimals: int): string

    The number with commas between groups of three digits and exactly decimals digits after the point: grouped(1234567.891, 2) is "1,234,567.89". Throws illegal_argument_exception if decimals is not between 0 and 15.

    static def grouped(number: decimal, decimals: int, separator: char, decimal_point: char): string

    grouped with your own characters, for other conventions: grouped(1234567.891, 2, '.', ',') is "1.234.567,89" and grouped(1234567, 0, ' ', '.') is "1 234 567". Throws illegal_argument_exception if decimals is not between 0 and 15.

    static def hex(number: decimal): string

    The whole number in hexadecimal with small letters: hex(255) is "ff", hex(0) is "0".

    static def hex(number: decimal, width: int): string

    hex(number) with at least width digits: hex(255, 4) is "00ff".

    static def hex_upper(number: decimal): string

    The whole number in hexadecimal with capital letters: hex_upper(255) is "FF".

    static def hex_upper(number: decimal, width: int): string

    hex_upper(number) with at least width digits: hex_upper(255, 4) is "00FF".

    static def integer(number: decimal): string

    The number as a whole number in base 10: integer(42) is "42", integer(-7) is "-7". A fraction is cut off, not rounded: integer(2.9) is "2" and integer(-2.9) is "-2" (use fixed(n, 0) to round).

    static def octal(number: decimal): string

    The whole number in octal: octal(8) is "10".

    static def ordinal(number: decimal): string

    The whole number with its English ordinal ending: ordinal(1) is "1st", ordinal(2) "2nd", ordinal(3) "3rd", ordinal(4) "4th", ordinal(11) "11th", ordinal(22) "22nd", ordinal(113) "113th". A fraction is cut off.

    static def padded(number: decimal, width: int): string

    The whole number with zeros in front until it has at least width digits: padded(7, 3) is "007", padded(1234, 3) is "1234". The minus sign of a negative number comes first and is not counted: padded(-7, 3) is "-007". Throws illegal_argument_exception if width is negative.

    static def percent(number: decimal, decimals: int): string

    The number as a percentage: percent(0.256, 1) is "25.6%", percent(1, 0) is "100%". The number is multiplied by 100 and rounded to decimals. Throws illegal_argument_exception if decimals is not between 0 and 15.

    static def plain(number: decimal): string

    A short readable form: a whole number without a point ("42"), anything else with up to 6 decimals and no zeros at the end ("0.1", "3.141593").

    static def roman(number: decimal): string

    The whole number as a Roman numeral: roman(4) is "IV", roman(1994) is "MCMXCIV". Throws illegal_argument_exception unless 1 <= number <= 3999 (Roman numerals have no zero and no standard form beyond 3999).

    static def scientific(number: decimal, decimals: int): string

    Scientific notation: one digit before the point, decimals digits after it, then the power of ten with a sign and at least two digits: scientific(31415.9, 2) is "3.14e+04", scientific(0.00012, 1) is "1.2e-04", scientific(0, 2) is "0.00e+00". Throws illegal_argument_exception if decimals is not between 0 and 15.

    static def to_radix(number: decimal, radix_base: int): string

    The whole number in base radix (2 to 36) with small letters for the digits above 9: to_radix(255, 16) is "ff", to_radix(35, 36) is "z". A negative number gets a minus sign: to_radix(-255, 16) is "-ff". Throws illegal_argument_exception if radix is not between 2 and 36, or if the number is 2^53 or larger (it would not be exact).

    static def to_radix(number: decimal, radix_base: int, width: int): string

    to_radix(number, radix_base) with zeros in front until there are at least width digits.

    static def trimmed(number: decimal, max_decimals: int): string

    The number with at most max_decimals digits after the point and no zeros at the end: trimmed(2.5, 4) is "2.5", trimmed(2, 4) is "2", trimmed(1.23456, 2) is "1.23". Throws illegal_argument_exception if max_decimals is not between 0 and 15.

    class number_parser

    source

    number_parser

    Turns text into numbers and says exactly what is wrong when it cannot. All functions are static: number_parser.parse_int("42").

    Every kind of number comes in three flavours (as in Kotlin):

    parse_int(text)             throws number_format_exception if text is not a number
parse_int_or_null(text)     returns null instead of throwing
parse_int_or(text, 0)       returns the given fallback instead of throwing

    and is_int / is_long / is_double only answer whether the text would parse.

    What counts as a number - integer: an optional '+' or '-' followed by at least one digit. With a radix (2 to 36) the digits are 0-9 and then the letters a-z / A-Z (parse_int("ff", 16) is 255). Nothing else is allowed: no spaces, no digit separators, no "0x" prefix (use decode() for prefixes). - int functions accept -2147483648 .. 2147483647 (32 bit). - long functions accept -9007199254740991 .. 9007199254740991: Sharp numbers are floating point and larger whole numbers are no longer exact. - decimal: [sign] digits [. digits] [e|E [sign] digits], where the digits before OR after the point may be left out ("5.", ".5") but not both. "NaN", "Infinity" and hexadecimal fractions are not accepted. - bool: "true" or "false" in any mix of capital and small letters.

    Surrounding whitespace is NOT ignored; trim() the text first if it may have some.

    Functions

    static def decode(text: string): decimal

    A whole number with an optional sign and an optional base prefix: "0x" / "0X" hexadecimal, "0b" / "0B" binary, "0o" / "0O" octal, otherwise decimal. decode("0xFF") is 255, decode("-0b101") is -5, decode("42") is 42. The range is that of parse_long. Throws number_format_exception if text is not such a number.

    static def is_double(text: string): bool

    true if parse_double(text) would succeed.

    static def is_int(text: string): bool

    true if parse_int(text) would succeed.

    static def is_long(text: string): bool

    true if parse_long(text) would succeed.

    static def parse_bool(text: string): bool

    true if text is "true", false if it is "false" (in any mix of capital and small letters). Throws number_format_exception for any other text ("yes", "1", "" ...).

    static def parse_bool_or(text: string, fallback: bool): decimal

    parse_bool(text) that returns fallback instead of throwing.

    static def parse_bool_or_null(text: string): boolean?

    parse_bool(text) that returns null instead of throwing.

    static def parse_double(text: string): decimal

    The decimal number written in text ("3.25", "-0.5", "1e3", ".5", "7"). Throws number_format_exception if text is not a decimal number (see the top of the file for the exact syntax).

    static def parse_double_or(text: string, fallback: double): decimal

    parse_double(text) that returns fallback instead of throwing.

    static def parse_double_or_null(text: string): double?

    parse_double(text) that returns null instead of throwing.

    static def parse_int(text: string): decimal

    The whole number written in text in base 10. Throws number_format_exception if text is empty, has anything but an optional sign and digits, or is outside of -2147483648 .. 2147483647.

    static def parse_int(text: string, radix: int): decimal

    The whole number written in text in base radix (parse_int("ff", 16) is 255, parse_int("-101", 2) is -5). Throws number_format_exception as parse_int(text) does, and illegal_argument_exception if radix is not between 2 and 36.

    static def parse_int_or(text: string, fallback: int): decimal

    parse_int(text) that returns fallback instead of throwing when text is not a valid int.

    static def parse_int_or_null(text: string): int?

    parse_int(text) that returns null instead of throwing when text is not a valid int.

    static def parse_int_or_null(text: string, radix: int): int?

    parse_int(text, radix) that returns null instead of throwing when text is not a valid int. (A radix outside of 2..36 still throws illegal_argument_exception: that is a mistake in the program, not in the text.)

    static def parse_long(text: string): decimal

    The whole number written in text in base 10, with the larger range -9007199254740991 .. 9007199254740991. Throws number_format_exception if text is not such a number.

    static def parse_long(text: string, radix: int): decimal

    parse_long in base radix (2 to 36). Throws number_format_exception, or illegal_argument_exception for a bad radix.

    static def parse_long_or(text: string, fallback: long): decimal

    parse_long(text) that returns fallback instead of throwing.

    static def parse_long_or_null(text: string): long?

    parse_long(text) that returns null instead of throwing.

    class regex

    source

    regex

    Regular expressions: patterns that describe text, for testing, searching, replacing and splitting.

    r := new regex("(\\d+)-(\\d+)");
r.matches("10-20")                      1   (the WHOLE text fits)
r.contains("from 10-20 to 30-40")       1   (it occurs somewhere)
m := r.find("from 10-20 to 30-40");     the first occurrence, or null
m.value()   "10-20"     m.group(1)   "10"     m.start()   5
r.find_all(text)                        every occurrence, as regex_match[]
r.replace_all("10-20", "\\2-\\1")       "20-10"
new regex(",\\s*").split("a, b,c")      ["a", "b", "c"]

    (In Sharp source a backslash in a string literal is written twice: the pattern \d+ is the literal "\\d+".)

    Pattern syntax abc the characters themselves . any character except a line feed [abc] [a-z] one character of the set / range; [^abc] one that is NOT in it \d \w \s a digit / a word character (letter, digit, _) / whitespace \D \W \S the opposites \n \t \r \f \v \0 line feed, tab, carriage return, form feed, vertical tab, NUL \xHH the character with hexadecimal code HH \. \* \\ ... a special character taken literally (any punctuation mark can be escaped) ^ $ the start / the end of the text \b \B a word boundary / not a word boundary x* x+ x? zero or more / one or more / zero or one x (as many as possible) x{3} x{2,} x{2,5} exactly 3 / at least 2 / between 2 and 5 times x*? x+? x?? x{2,5}? the same, but as FEW as possible ("lazy") (x) a group: keeps what it matched, numbered from 1 by its '(' (?:x) a group that only groups and keeps nothing a|b a or b (the first alternative that leads to a match wins)

    Not supported: back-references inside a pattern (\1), look-ahead and look-behind, named groups, Unicode classes. ^ and $ do not match at line breaks inside the text. Characters are single bytes (ASCII).

    How it works, and what it costs The pattern is translated once, in the constructor, into a small program; matching runs that program with an explicit stack (no recursion, so long texts cannot overflow the call stack). Every (program step, text position) pair is tried at most once per search, so there is no "catastrophic backtracking": the time is at most proportional to pattern size x text length, and a search uses about (pattern size x text length) / 30 numbers of working memory, which the regex object keeps for the next search. Because of that working memory one regex object must not be used by two threads at the same time; make one object per thread.

    Keep the regex object when a pattern is used more than once: translating the pattern is the expensive part for short texts.

    Functions

    regex(pattern: string)

    Translates pattern. Capital and small letters are different. Throws parse_exception, saying what is wrong and at which position, if the pattern is not valid (unbalanced parentheses or brackets, a quantifier with nothing to repeat, an unknown escape ...).

    regex(pattern: string, ignore_case: bool)

    Translates pattern; if ignore_case is true, ASCII capital and small letters are treated as equal ("abc" also matches "ABC", "[a-c]" also 'B'). Throws parse_exception if the pattern is not valid.

    def contains(text: string): bool

    true if the pattern matches somewhere in the text.

    def count(text: string): decimal

    How many (non-overlapping) matches the text has.

    static def escape(text: string): string

    text with a backslash in front of every character that is special in a pattern, so the result matches exactly that text: regex.escape("1+1=2?") is the pattern 1\+1=2\?

    def find(text: string): regex_match?

    The first (leftmost) match in the text, or null if there is none.

    def find(text: string, start: int): regex_match?

    The first match that starts at position start or later, or null. (^ still means the start of the whole text, not start.) Throws out_of_bounds_exception if start is negative or beyond the end of the text.

    def find_all(text: string): regex_match[]

    Every match in the text, left to right, not overlapping, as an array (length 0 if there is none). After an empty match the search moves on by one character, so a pattern that can match "" terminates.

    def group_count(): decimal

    How many capturing groups "( ... )" the pattern has (group 0, the whole match, is not counted).

    def index_of(text: string): decimal

    Position of the first match in the text, or -1 if there is none.

    static def is_match(pattern: string, text: string): bool

    One-off test: true if pattern matches somewhere in text. Throws parse_exception for a bad pattern.

    def matches(text: string): bool

    true if the WHOLE text fits the pattern (new regex("\\d+").matches("123") is 1, matches("123a") is 0).

    static def matches(pattern: string, text: string): bool

    One-off test: true if the WHOLE text fits pattern. Throws parse_exception for a bad pattern.

    def pattern(): string

    The pattern text this object was made from.

    def replace_all(text: string, replacement: string): string

    The text with every match replaced by replacement. In the replacement \1 .. \9 stand for what the groups matched and \0 for the whole match (written "\\1" in Sharp source; $1 is accepted as well); \\ gives a backslash. new regex("(\\w+)=(\\w+)").replace_all("a=1", "\\2=\\1") is "1=a". A text without a match is returned as an unchanged copy. Throws illegal_argument_exception if the replacement refers to a group the pattern does not have.

    def replace_first(text: string, replacement: string): string

    Like replace_all, but only the first (leftmost) match is replaced.

    def split(text: string): string[]

    The parts of the text between matches: new regex("\\s*,\\s*").split("a , b,c") is ["a", "b", "c"]. As with string.split, empty parts are kept (",a,".split gives ["", "a", ""]) and a text without a match gives an array holding the whole text. An EMPTY match never produces an empty part at the very start or end, so new regex("").split("abc") is ["a", "b", "c"].

    def split(text: string, limit: int): string[]

    Like split(text), but returns at most limit parts: the last part holds the rest of the text. A limit of 0 means no limit. Throws illegal_argument_exception if limit is negative.

    class regex_match

    source

    regex_match

    One place where a std.text#regex matched: where it starts and ends, the matched text, and what each group "( ... )" of the pattern matched.

    m := new regex("(\\w+)@(\\w+)").find("mail ada@example now");
m.value()       "ada@example"
m.start()       5          (index of the first matched character)
m.end()         16         (index just after the last one)
m.group(1)      "ada"
m.group(2)      "example"

    Group 0 is the whole match; groups are numbered from 1 by the position of their opening parenthesis. A group that took no part in the match - for example the "(b)" in "a|(b)" when "a" matched - has start and end -1 and the text ""; has_group(n) tells it apart from a group that matched "".

    Objects of this class are made by regex (find, find_all); a match keeps a reference to the text it was found in and does not change afterwards.

    scanner

    Reads words, numbers and lines out of a text, one after the other (like Java's Scanner, but over a string):

    input := new scanner("width 42 3.5\nsecond line");
name  := input.next();             // "width"
count := input.next_int();         // 42
ratio := input.next_double();      // 3.5
input.next_line();                 // "" (the rest of the first line)
rest  := input.next_line();        // "second line"

    Tokens are separated by whitespace (space, tab, \n, \r, vertical tab, form feed), or by the characters given to the two-argument constructor. Any number of separators may sit between two tokens.

    The has_next... functions look ahead without reading anything, so the usual pattern is while(input.has_next_int()) { total += input.next_int(); }. A next_int / next_double / next_bool that finds a token of the wrong kind throws number_format_exception and does NOT read the token, so it can still be read with next(). Every next... throws no_such_element_exception when the text is used up.

    To read user input, read a line with read_line() and scan that.

    string_reader

    A cursor over a string, for writing parsers by hand: look at the next character without taking it (peek), take it (next), skip or collect runs of characters, and try to match fixed pieces of text.

    r := new string_reader("width = 42;");
name := r.read_identifier();        // "width"
r.skip_whitespace();
r.expect("=");                      // throws parse_exception if something else is there
r.skip_whitespace();
digits := r.read_digits();          // "42"
r.match(";");                       // 1, and the reader is at the end

    Characters are returned as native numbers; -1 means "end of the text", so while((c = r.next()) >= 0) style loops need no separate end test. Nothing here throws at the end of the text except expect() and the mark misuse described below: reading past the end simply gives -1 or "".

    The position can be saved and restored (mark / reset, or position / seek) to try one way of reading and go back if it does not work out. line() and column() say where the cursor is for error messages.

    string_similarity

    Measures of how alike two strings are. All functions are static.

    levenshtein(a, b)          edits (insert / delete / replace one character) to turn a into b
damerau_levenshtein(a, b)  the same, but swapping two neighbouring characters is one edit
hamming(a, b)              positions at which two strings of equal length differ
similarity(a, b)           0.0 .. 1.0 from the Levenshtein distance (1 = equal)
jaro / jaro_winkler        0.0 .. 1.0, good for short strings such as names
common_prefix / common_suffix (+ _length)
longest_common_substring   the longest piece both strings contain
lcs_length                 length of the longest common SUBSEQUENCE (need not be adjacent)

    Comparisons are exact: capital and small letters are different. Call to_lower() on both strings first for a comparison that ignores case.

    Cost: the distance and common-part functions take time proportional to length(a) * length(b) and memory proportional to the shorter length or length(b); they are meant for words and lines, not for whole files.

    Functions

    static def common_prefix(a: string, b: string): string

    The start both strings share ("" if they start differently): common_prefix("interstellar", "internet") is "inter".

    static def common_prefix_length(a: string, b: string): decimal

    The number of characters both strings start with: common_prefix_length("interstellar", "internet") is 5.

    static def common_prefix_of(items: string[]): string

    The start shared by ALL strings of items: for ["flower", "flow", "flight"] it is "fl". An empty array gives ""; one string gives that string.

    static def common_suffix(a: string, b: string): string

    The end both strings share ("" if they end differently): common_suffix("walking", "talking") is "alking".

    static def common_suffix_length(a: string, b: string): decimal

    The number of characters both strings end with: common_suffix_length("walking", "talking") is 6.

    static def damerau_levenshtein(a: string, b: string): decimal

    Like levenshtein, but swapping two neighbouring characters counts as ONE edit instead of two (the "optimal string alignment" distance): the typical typing mistake. damerau_levenshtein("form", "from") is 1.

    static def hamming(a: string, b: string): decimal

    The Hamming distance: at how many positions the two strings have a different character. hamming("karolin", "kathrin") is 3. Throws illegal_argument_exception if the strings do not have the same length.

    static def jaro(a: string, b: string): decimal

    The Jaro similarity, 0 (nothing alike) to 1 (equal). It counts characters that match within a window around the same position, and how many of those are out of order. jaro("MARTHA", "MARHTA") is about 0.944. Two empty strings give 1; one empty string gives 0.

    static def jaro_winkler(a: string, b: string): decimal

    The Jaro-Winkler similarity: jaro, raised for strings that start the same (up to 4 characters), which suits names and words. jaro_winkler("MARTHA", "MARHTA") is about 0.961.

    static def lcs_length(a: string, b: string): decimal

    The length of the longest common SUBSEQUENCE: the most characters that appear in both strings in the same order, not necessarily next to each other. lcs_length("AGGTAB", "GXTXAYB") is 4 ("GTAB").

    static def levenshtein(a: string, b: string): decimal

    The Levenshtein (edit) distance: the smallest number of single-character insertions, deletions and replacements that turn a into b. levenshtein("kitten", "sitting") is 3. Equal strings give 0; the distance to "" is the length of the other string.

    static def longest_common_substring(a: string, b: string): string

    The longest piece of text that occurs in both strings without gaps: longest_common_substring("xabcdy", "zabcdw") is "abcd". If several are equally long the one that comes first in a is returned; "" if the strings share no character.

    static def similarity(a: string, b: string): decimal

    How alike the strings are on a scale from 0 (nothing in common) to 1 (equal): 1 - levenshtein / length of the longer string. similarity("kitten", "sitting") is about 0.571. Two empty strings give 1.

    string_tokenizer

    Walks through a text token by token, where tokens are the runs of characters between delimiter characters (Java's StringTokenizer):

    t := new string_tokenizer("a, b;c", ",; ");

    template

    A text with named placeholders in braces that are filled in later:

    t := new template("Dear {name}, your order {id} ships on {day}.");
t.put("name", "Ada").put_int("id", 1042).put("day", "Monday");
t.render()        "Dear Ada, your order 1042 ships on Monday."

    Rules - a placeholder is '{', a name, '}'. A name is made of letters, digits, '_', '.' and '-'; spaces directly inside the braces are ignored, so "{ name }" is the same as "{name}". - "{{" gives one '{' and "}}" gives one '}' (to write braces as text). - anything else in braces is not a placeholder and is copied as it is: "{}", "{a b}", "{x:y}", and a '{' that is never closed. - a placeholder whose name has no value is, by default, left in the output unchanged ("{day}"), so missing values are easy to spot. Choose another behaviour with set_missing_value("") or set_strict(true). - values are inserted as they are; a value containing "{x}" is NOT filled in again.

    The same template can be rendered many times with changing values: put() with a name that already has a value replaces it.

    text_align

    Puts one line of text into a field of a given width. All functions are static:

    class text_pattern

    source

    text_pattern

    Wildcard ("glob") matching, the kind used for file names:

    *        any run of characters, including none
?        exactly one character
[abc]    one character out of the set
[a-z0-9] one character out of the ranges (sets and ranges can be mixed)
[!abc]   one character that is NOT in the set ( [^abc] means the same )
\x       the character x itself, e.g. \* for a real star

    Inside brackets a ']' directly after the '[' (or after the '!') is a normal member of the set, and a '-' at the start or end is a normal minus.

    p := new text_pattern("*.sharp");
p.matches("main.sharp")        1
p.matches("main.cpp")          0
text_pattern.matches("data_??.csv", "data_07.csv")     1

    A pattern always has to match the WHOLE text (use "*abc*" to ask whether "abc" occurs somewhere). The '*' also matches '/' - there is no special treatment of path separators.

    Making a text_pattern checks and translates the pattern once; matching is then a single pass over the text with no recursion, so long texts and patterns with many stars are safe. Keep the object when the same pattern is used many times.

    For patterns that need repetition counts, groups or alternatives see std.text#regex.

    class text_table

    source

    text_table

    Lays out rows of text in columns for printing in a terminal or a log:

    t := new text_table(new string[] { "item", "qty", "price" });
t.align(1, text_table.right).align(2, text_table.right);
t.add_row(new string[] { "pear", "3", "1.20" });
t.add_row(new string[] { "melon", "12", "24.00" });
println(t.render());
    +-------+-----+-------+
| item  | qty | price |
+-------+-----+-------+
| pear  |   3 |  1.20 |
| melon |  12 | 24.00 |
+-------+-----+-------+

    Every column is as wide as its widest cell (header included). Columns are left aligned unless align() says otherwise. With set_border(false) the frame is left out and columns are separated by two spaces, with a line of dashes under the headers:

    item   qty  price
-----  ---  -----
pear     3   1.20

    Cells are single lines; a line end inside a cell would break the layout (render does not check for it). Width is counted in characters (bytes). render() can be called any number of times, also between add_row calls.

    Fields

    leftdecimalalign(column, text_table.left): the cell text starts at the left edge of the column (the default).
    rightdecimalalign(column, text_table.right): the cell text ends at the right edge of the column (for numbers).
    centerdecimalalign(column, text_table.center): the cell text is in the middle of the column.

    Functions

    A table with one column per header. Throws illegal_argument_exception if there are no headers.

    def add_row(row: string[]): text_table

    Adds a row. A row with fewer cells than the table has columns is filled up with empty cells; null cells count as empty. Throws illegal_argument_exception if the row has MORE cells than columns.

    def align(column: int, mode: int): text_table

    Sets how column column (0 = first) is aligned: text_table.left, text_table.right or text_table.center. The header is aligned the same way. Returns this table, so calls can be chained. Throws out_of_bounds_exception if there is no such column, illegal_argument_exception if mode is not one of the three values.

    def cell(row: int, column: int): string

    The text of the cell in row row, column column (both from 0). Throws out_of_bounds_exception if there is no such cell.

    def clear(): text_table

    Removes all rows. Headers, alignment and the border setting are kept.

    def column_count(): decimal

    The number of columns.

    def render(): string

    The whole table as text: one line per row, each line ending in "\n" (including the last one), ready for print().

    def render_lines(): string[]

    The lines of render() as an array, without the line ends.

    def row_count(): decimal

    The number of rows added so far (the header row is not counted).

    true (the default) draws the frame of + - | characters; false gives the plain layout.

    Same as render(), so a table can be printed directly.

    class text_wrap

    source

    text_wrap

    Breaks long text into lines of a maximum width, and adds or removes indentation. All functions are static:

    text_wrap.wrap("the quick brown fox jumps", 10)     ["the quick", "brown fox", "jumps"]
text_wrap.fill("the quick brown fox jumps", 10)     "the quick\nbrown fox\njumps"
text_wrap.indent("a\nb", "  ")                      "  a\n  b"
text_wrap.dedent("    a\n      b")                  "a\n  b"

    How wrapping works - the text is cut into words at whitespace; words are put on a line with single spaces between them for as long as they fit - a word longer than the width is cut into pieces of exactly the width (there is no hyphenation), so no line is ever longer than the width - line ends in the input are treated like spaces by wrap(); fill() and wrap_paragraphs() keep EMPTY lines as paragraph breaks - width is counted in characters (bytes): right for ASCII text

    Functions

    static def dedent(text: string): string

    The text with the indentation that ALL its lines share removed, so the least indented line starts at column 0 and the others keep their relative indentation. Blank lines are ignored when measuring and come out empty. Only spaces and tabs count as indentation, each as one character. Line ends are written as "\n".

    static def fill(text: string, width: int): string

    The text wrapped to width as ONE string with "\n" between the lines. Paragraph breaks (empty lines) are kept, as in wrap_paragraphs. There is no "\n" after the last line. A blank text gives "". Throws illegal_argument_exception if width is less than 1.

    static def fill(text: string, width: int, first_prefix: string, rest_prefix: string): string

    Wraps the text so that, together with the prefixes, no line is longer than width: the first line starts with first_prefix, all following lines with rest_prefix. Used for bullet points and hanging indents: fill("some long text ...", 20, "- ", " "). Throws illegal_argument_exception if width does not leave at least one character of room after the longer prefix.

    static def indent(text: string, prefix: string): string

    Every line of the text with prefix in front of it. Lines that are empty stay empty (no trailing spaces are produced). Line ends are written as "\n".

    static def indent_by(text: string, spaces: int): string

    indent with spaces spaces as the prefix. A count of 0 or less changes nothing but the line ends. (It has its own name because indent(text, 3) would be ambiguous: a number also converts to a string.)

    static def max_line_length(text: string): decimal

    The length of the longest line of the text (0 for "").

    static def wrap(text: string, width: int): string[]

    The text as lines of at most width characters, as an array. All whitespace (including line ends) only separates words. An empty or blank text gives an array of length 0. Throws illegal_argument_exception if width is less than 1.

    static def wrap_paragraphs(text: string, width: int): string[]

    Like wrap, but empty (or blank) lines in the text are kept as paragraph breaks: each paragraph is wrapped on its own and an empty string is put between two paragraphs. Several empty lines in a row give one break. Throws illegal_argument_exception if width is less than 1.
