Projects

One folder, one command.

A project is a folder with a settings.json and your code in src. The compiler finds the files itself.

Project layout

Sharpcraft, a small block-building game written in Sharp. Each file names its module with a mod line.

sharpcraft/
  settings.json
  src/
    main.sharp              mod app
    game/game.sharp         mod craft.game
    world/blocks.sharp      mod craft.world
    world/noise.sharp       mod craft.world
    player/walker.sharp     mod craft.player
    items/pockets.sharp     mod craft.items
    ui/hud.sharp            mod craft.ui
  build/
    outputs/sharpcraft      the built program

settings.json

The project's configuration.

{
  "name": "sharpcraft",
  "version": "1.0",
  "output": "sharpcraft",
  "ignore_folders": [ "build" ]
}
output
the program's name, written to build/outputs
ignore_folders
folders the compiler should skip
optimize_level
turn the optimizer on for every build
extern_lib
extra Sharp libraries to include
c_libraries
where to find the C libraries you call

Build and run

Build with sharpc -p, then run the program.

$ cd sharpcraft
$ sharpc -p
$ sharp build/outputs/sharpcraft

Importing modules

Import a module to use its code.

mod app;

import (
    std,
    std.guikit.*,
    craft.game
)

def main(args: string[]) {
    game := new sharpcraft();
    gui.run("Sharpcraft", 1280, 720, game);
}
